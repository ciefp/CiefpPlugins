📺 CiefpXfiles — IPTV-плагин (Xtream) для Enigma2
CiefpXfiles — это продвинутый IPTV-плагин для Enigma2 (Python 3), позволяющий просматривать потоки Xtream Codes через современный интерфейс в формате FHD. Плагин автоматически загружает постеры и описания из баз данных TMDB/OMDb, а также переводит описания на сербский язык с помощью нейросети GROQ AI.

Разработка плагина была сосредоточена на оптимизации, стабильности и, прежде всего, на качестве визуального оформления. Особое внимание уделено интерфейсу в формате FHD, высокой производительности и автоматическому обогащению контента (постеры, описания, рейтинги).
Плагин создан путем объединения нескольких моих предыдущих разработок:
- Интеграция с TMDB/OMDb (на основе плагина CiefpTMDBsearch).
- Подключение к порталам (на основе плагина CiefpE2Converter).
- Перевод описаний сюжетов с использованием API-ключа GROQ (на основе плагина CiefpEPGinfo).
Значительный вклад в реализацию этих идей внесла нейросеть Deepseek, которая помогла мне воплотить в жизнь задуманное и выполнить поставленные технические требования.

✨ Основные возможности
Поддержка Xtream Codes и M3U — введите данные вашего плейлиста или учетные данные Xtream.
Интерфейс FHD — современный дизайн с тремя панелями (категории, информация, постер).
Интеграция с TMDB и OMDb — автоматическое отображение постеров, описаний, актерского состава, режиссеров и рейтингов IMDb.
Перевод через GROQ AI — автоматический перевод описаний фильмов на сербский (или другой) язык.
Поиск — быстрый поиск фильмов и сериалов по названию (с помощью кнопки INFO).
Статус портала — индикаторы (зеленый/красный) для отображения состояния сервера (онлайн/офлайн). Автоматическое обновление — плагин уведомляет о выходе новой версии.
Системная папка — все данные сохраняются в директории /etc/enigma2/CiefpXfiles/.

⚙️ Настройка
После установки откройте плагин через меню. При первом запуске потребуется ввести API-ключи.
Нажмите кнопку MENU (или выберите SETTINGS в нижней части экрана). Введите следующие ключи:
API-ключ TMDB — можно получить бесплатно на сайте themoviedb.org. -- (tmdbapikey.txt)
API-ключ OMDb — можно получить бесплатно на сайте omdbapi.com. -- (omdbapikey.txt)
API-ключ GROQ — можно получить бесплатно на сайте console.groq.com. -- (groqapikey.txt)
API-ключ SUBDL — необязательный, для субтитров. -- (subdlapikey.txt)
API-ключ SUBDL в данный момент не используется, но добавлен с прицелом на будущие версии.

Место для хранения API-ключей: /etc/enigma2/CiefpXfiles/keys/
Настройте язык субтитров, тип плеера и другие параметры.
Нажмите зеленую кнопку (Сохранить). 📂 Расположение и файлы:
/etc/enigma2/CiefpXfiles/
playlist.txt
portals_cache.json
/etc/enigma2/CiefpXfiles/keys/
tmdbapikey.txt, omdbapikey.txt, groqapikey.txt, subdlapikey.txt
/etc/enigma2/CiefpXfiles/posters/
/etc/enigma2/CiefpXfiles/subtitles/
/etc/enigma2/CiefpXfiles/epg/

📂 Новая структура файлов (безопасность):
Все ваши данные (API-ключи, кэш постеров, плейлисты) теперь хранятся в защищенном месте: /etc/enigma2/CiefpXfiles/.
Это означает, что при обновлении или переустановке плагина ваши ключи и списки сохранятся. 📁 Playlist.txt
Добавить данные в плейлист можно двумя способами:

Формат A (структурированный)
text
Host:http://server:port
Username: xxxx
Password: xxxx
m3u:http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
EPG: http://server:port/xmltv.php?username=xxxx&password=xxxx

Формат B (только M3U-ссылки)
text
http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
http://server:port/xmltv.php?username=xxxx&password=xxxx
Файл playlist.txt находится по пути: /etc/enigma2/CiefpXfiles/playlist.txt.

🎮 Управление с пульта
Кнопка	Функция
OK	Открыть категорию / Запустить поток
EXIT	Закрыть плагин
Зеленая	Прямой эфир (Live TV)
Желтая	Фильмы
Синяя	Сериалы
MENU	Настройки
INFO	Поиск


🛠️ Техническая информация
Python: 3
Поддерживаемые имиджи: OpenATV, OpenPLi, OpenViX, OpenBH, Pure2, EGAMI
Плееры: Exteplayer3 (5002), GStreamer (5001), GStreamer (4097)
Кэш: /etc/enigma2/CiefpXfiles/ (постеры, EPG, ключи)
