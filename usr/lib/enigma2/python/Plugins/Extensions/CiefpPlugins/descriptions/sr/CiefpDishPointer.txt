
CiefpDishPointer v1.1
Plugin za Enigma2 (Python 2 i Python 3)

OPIS:
Plugin koji pomaže početnicima da podele antenu — da odrede nulti
satelit, da provere da li je antena dobro podešena, i da dobiju
sve potrebne uglove za podešavanje (azimut, elevacija, LNB skew).

Radi po principu sajta dishpointer.com, prilagođen Enigma2 sistemu.
Python2 nisam testirao


GLAVNE FUNKCIJE:

▶ Automatska geolokacija
- Detekcija lokacije preko IP adrese (ip-api.com)
- Prikazuje: kontinent, državu, grad, geografsku širinu i dužinu
- Mogućnost ručne izmene preko INFO tastera

▶ Četiri režima rada
- Svi sateliti — prikazuje najbliži satelit vašoj lokaciji
- Motorizovani — izračunava True South/North i deklinaciju
- Multi LNB — birate više satelita, plugin proračuna nulti
- Pojedinačni — birate jedan satelit iz liste

▶ Izračunavanje
- Azimut pravi i magnetni
- Elevacija tanjira
- LNB skew (Left/Right)
- Deklinacija za motorizovane sisteme

▶ Single Satellite (zeleno dugme)
- Lista svih satelita iz satellites.xml
- Izbor jednog satelita strelicama
- Prikazuje izračunate uglove za izabrani satelit

▶ Multi LNB (žuto dugme)
- Checkbox lista satelita
- Označavate više satelita koje pratite
- Plugin proračuna koji je najbolji nulti satelit
- Prikazuje listu izabranih satelita i srednju poziciju

▶ Slike pomoći (plavo dugme)
- Slikovito objašnjenje za:
• Elevaciju (premala/prevelika)
• Azimut (pogrešna osa)
• Deklinaciju (prevelika/premala)
• LNB Skew
• True South
• Podešavanje motora (4 primera)

▶ Signal u realnom vremenu
- SNR sa gradijent barom (crveno → žuto → zeleno)
- AGC sa gradijent barom
- DB vrednost (npr. 16.38)
- Prikaz trenutnog kanala, provajdera i satelita

▶ Dvojezična podrška
- Engleski (default)
- Srpski
- Promena preko MENU tastera → Settings → Language


DUGMIĆI NA EKRANU / TASTERI:

CRVENO (EXIT) — zatvara plugin
ZELENO (SINGLE SAT) — otvara izbor pojedinačnog satelita
ŽUTO (MULTI LNB) — otvara Multi LNB setup
PLAVO (HELP IMAGES) — otvara slike objašnjenja
MENU (LANGUAGE) — otvara Settings (jezik, lokacija, refresh)
INFO (LOCATION) — otvara ručnu izmenu lokacije
LEVO/DESNO — menja tip sistema (All/Motorised/Multi/Single)
EXIT — zatvara plugin
