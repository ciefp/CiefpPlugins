Το CiefpChannelHistory είναι ένα πρόσθετο (plugin) για το Enigma2 που
καταγράφει το ιστορικό προβολής τηλεοπτικών καναλιών και παρέχει
λεπτομερή στατιστικά στοιχεία, διαθέτοντας οθόνη πληροφοριών EPG
σε ανάλυση FHD, εμπλουτισμένη με δεδομένα από τα TMDB/OMDb.

Η ιδέα για αυτό το πρόσθετο προέκυψε από δύο προγενέστερα πρόσθετα:
• CiefpTMDBinfo
• CiefpEPGinfo

Συνδυάζοντας τη λειτουργικότητα αυτών των δύο πρόσθετων,
δημιουργήθηκε το CiefpChannelHistory — ένα ολοκληρωμένο εργαλείο
για την παρακολούθηση και την ανάλυση της τηλεθέασης καναλιών.

Για να διασφαλιστεί ότι τα στατιστικά στοιχεία είναι όσο το δυνατόν
πιο ακριβή και ρεαλιστικά, το πρόσθετο απαιτεί μερικές ημέρες χρήσης.

Το πρόσθετο καταγράφει την τηλεθέαση από τη στιγμή της εγκατάστασης.
Όσο περισσότερο χρησιμοποιείτε το πρόσθετο, τόσο πιο ακριβή
γίνονται τα στατιστικά στοιχεία:

• Πρώτη ημέρα    → βασικά στατιστικά (λίγα κανάλια)
• 3-5 ημέρες     → ρεαλιστική εικόνα της τηλεθέασης
• 7+ ημέρες      → αξιόπιστα στατιστικά ανά ώρα και ημέρα
• 30+ ημέρες     → πλήρης ανάλυση των συνηθειών θέασης

Συνιστούμε να αφήσετε το πρόσθετο να λειτουργεί χωρίς να διαγράψετε
τη βάση δεδομένων για τουλάχιστον 3-5 ημέρες, προτού βγάλετε
συμπεράσματα σχετικά με τις συνήθειες θέασής σας.

Τα στατιστικά στοιχεία αποθηκεύονται σε βάση δεδομένων SQLite
και διατηρούνται ακόμη και μετά από επανεκκινήσεις του Enigma.
Μπορείτε να τα διαγράψετε μέσω της διαδρομής Ρυθμίσεις →
Διαγραφή Όλου του Ιστορικού (Settings → Clear All History),
εάν επιθυμείτε να ξεκινήσετε από την αρχή. 🎯 ΚΥΡΙΑ ΧΑΡΑΚΤΗΡΙΣΤΙΚΑ

▶ Ιστορικό προβολής καναλιών
• Αυτόματη καταγραφή κάθε καναλιού που παρακολουθείτε
• Καταγραφή διάρκειας, αριθμού προβολών και χρονικής σήμανσης τελευταίας προβολής
• Βάση δεδομένων SQLite με λειτουργία WAL για αξιοπιστία

▶ Κύρια οθόνη FHD (1920x1080)
• Λίστα των τελευταίων 15 καναλιών (ιστορικό)
• Εμφάνιση του τρέχοντος καναλιού στο επάνω μέρος
• Πληροφορίες EPG + αφίσα TMDB + διανομή ρόλων
• Εικονίδια καναλιών (picons)

▶ Οθόνη πληροφοριών EPG FHD (κίτρινο κουμπί)
• Λίστα συμβάντων EPG για το επιλεγμένο κανάλι
• Λεπτομέρειες TMDB (αφίσα, είδος, σκηνοθέτης, περιγραφή)
• Βαθμολογία IMDb
• Διανομή ρόλων και συντελεστές με εικόνες
• Περιήγηση στη φιλμογραφία
• Αναπαραγωγή τρέιλερ μέσω yt-dlp

▶ Στατιστικά στοιχεία (πράσινο κουμπί)
• Επισκόπηση: αριθμός καναλιών, συνεδρίες, συνολικός χρόνος
• Κορυφαία 20 κανάλια: τα κανάλια με τη μεγαλύτερη τηλεθέαση
• Ανά τύπο υπηρεσίας: DVB-S, DVB-T, IPTV
• Ανά δορυφόρο: 20+ δορυφόροι με τα ονόματά τους
• Ανά κωδικοποίηση: FTA, Irdeto, NDS, Nagravision...
• Ανά ώρα της ημέρας: ώρες αιχμής τηλεθέασης
• Ανά ημέρα της εβδομάδας: σύγκριση καθημερινών με Σαββατοκύριακο
• Συνήθειες προβολής: τι παρακολουθείτε συνήθως τη συγκεκριμένη ώρα

▶ Ανίχνευση δορυφόρου
• Ανάγνωση namespace από το service reference
• Αντιστοίχιση με το όνομα δορυφόρου από το satellites.xml
• Υποστήριξη DVB-S, DVB-T, DVB-C
• Εμφάνιση θέσης + ονόματος (π.χ. "23.5E (Astra 3C)")

▶ Ανίχνευση CAID
• Ανάγνωση ενεργών CAID από το service.info()
• Ανάγνωση ενεργού CAID από το /tmp/ecm.info
• Εμφάνιση πληροφοριών για όλα τα CAID με τα ονόματα των συστημάτων
• Υποστήριξη: Irdeto, NDS, Nagravision, Conax,
Cryptoworks, Viaccess, Seca, PowerVu, Biss...

▶ Φίλτρο περιεχομένου για ενήλικες (γονικός έλεγχος)
• Ανάγνωση της μαύρης λίστας (blacklist) από το /etc/enigma2/blacklist
• Παράκαμψη καναλιών για ενήλικες στατιστικά στοιχεία
• Προαιρετικά: Ενεργοποίηση/Απενεργοποίηση (ON/OFF) στις Ρυθμίσεις
• Αυτόματη ενημέρωση κατά την αλλαγή του γονικού ελέγχου

▶ Οθόνη ρυθμίσεων (μπλε κουμπί)
• Φάκελος βάσης δεδομένων (HDD/USB/tmp)
• Μέγεθος ιστορικού (10-50)
• Ελάχιστος χρόνος προβολής (5-300 δευτ.)
• Χρόνος καθυστέρησης/απόρριψης επαναλαμβανόμενων σημάτων (Debounce) (3-60 δευτ.)
• Διάρκεια διατήρησης ιστορικού (30/60/90/180/365 ημέρες/Για πάντα)
• Φίλτρο περιεχομένου για ενήλικες (γονικός έλεγχος): ΝΑΙ/ΟΧΙ
• Κλειδιά API: TMDB, OMDb, GROQ
• Εμφάνιση βαθμολογίας IMDB: ΝΑΙ/ΟΧΙ
• Λήψη αφισών: ΝΑΙ/ΟΧΙ
• Γλώσσα: 9 γλώσσες
• Εκκαθάριση παλαιών συνεδριών
• Εκκαθάριση προσωρινής μνήμης (cache)
• Εκκαθάριση όλου του ιστορικού
• Χειροκίνητη ενημέρωση

💡 ΑΠΑΙΤΗΣΕΙΣ
-

• Image Enigma2 (δοκιμασμένο σε OpenATV 8.0)
• Python 3
• python3-sqlite3
• python3-requests
• Κλειδί API TMDB (δωρεάν: https://www.themoviedb.org/settings/api)
• Κλειδί API OMDb (δωρεάν: https://www.omdbapi.com/apikey.aspx)
• GROQ: Κλειδί API (δωρεάν: https://console.groq.com/keys)


⚙️ ΠΩΣ ΝΑ ΑΠΟΚΤΗΣΕΤΕ ΚΛΕΙΔΙΑ API
-

1) Κλειδί API TMDB
• Εγγραφείτε στο https://www.themoviedb.org/
• Μεταβείτε στις Ρυθμίσεις (Settings) → API → Αίτημα για κλειδί API (Request API Key)
• Αντιγράψτε το κλειδί API

2) Κλειδί API OMDb
• Μεταβείτε στο https://www.omdbapi.com/apikey.aspx
• Επιλέξτε το δωρεάν πακέτο (Free - όριο 1.000 αιτημάτων ημερησίως)
• Αντιγράψτε το κλειδί API από το email που θα λάβετε

3) Εισαγάγετε τα κλειδιά στο πρόσθετο (plugin):
• Ανοίξτε το CiefpChannelHistory
• Μπλε κουμπί (Ρυθμίσεις)
• Κλειδί API TMDB → OK → εισαγωγή κλειδιού
• Κλειδί API OMDb → OK → εισαγωγή κλειδιού
• GROQ: Κλειδί API → OK → εισαγωγή κλειδιού
• Αποθήκευση (πράσινο κουμπί)

Εναλλακτικά – αρχεία
Μπορείτε επίσης να δημιουργήσετε χειροκίνητα αρχεία στον φάκελο του πρόσθετου (plugin):
- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/tmdbapikey.txt
- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/omdbapikey.txt
- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/groqapikey.txt
