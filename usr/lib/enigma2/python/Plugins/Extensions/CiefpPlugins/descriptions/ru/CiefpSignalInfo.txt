Краткое описание
Продвинутый плагин для отображения информации о сигнале и канале на ресиверах с Enigma2.
Поддерживает тюнеры стандартов DVB-S/S2, DVB-T/T2 и DVB-C/C2.
Отображает подробные технические параметры, данные о кодировке, PID и информацию о сигнале в реальном времени.
Включает мини-скин, позволяющий быстро проверять сигнал и переключать каналы, не выходя из текущего режима просмотра.

CiefpSignalInfo (основной экран)
✅ Отображение всей информации о канале (название канала, провайдер, спутник)
✅ DVB-S/S2: частота, поляризация, символьная скорость, FEC, модуляция, система, режим/код PLS
✅ DVB-T/T2: канал (номер канала), частота, полоса пропускания, скорость кодирования (HP/LP), созвездие (модуляция), режим передачи (Trans.) Режим (Mode), Защитный интервал (Guard Int.), Иерархия (Hierarchy)
✅ DVB-C/C2: Частота, Символьная скорость, Модуляция, FEC, Система
✅ PID (видео, аудио, PCR, PMT, телетекст)
✅ Шифрование (список CAID + маркер [ACTIVE])
✅ SI/TS/ONID
✅ Идентификатор сервиса (Service Reference)
✅ Пикон (для DVB-S и DVB-T)
✅ Название спутника (для DVB-S)
✅ Шкалы SNR/AGC + % + дБ
✅ Время и дата
✅ Зеленая кнопка → Satfinder (с отображением сигнала и отсутствием ошибок)
✅ Синяя кнопка → Мини-скин

CiefpSignalInfoMini (мини-скин, по центру вверху)
✅ Пикон + название канала
✅ Шкалы SNR/AGC + %
✅ Значение в дБ
✅ Параметры в 3 строки (Частота/Поляризация, SR/FEC, Система/Модуляция для DVB-S; Канал:24 498 МГц, CR/Созвездие, Система/Режим для DVB-T)
✅ Переключение каналов стрелками «влево»/«вправо»
✅ Список каналов стрелками «вверх»/«вниз»
✅ Автообновление при смене канала
✅ Автоматическое закрытие через 15 с
✅ Закрытие кнопками EXIT, OK или синей кнопкой

## Кнопки:

Кнопка	Функция
🔴 КРАСНАЯ	Закрыть плагин
🟢 ЗЕЛЕНАЯ	Открыть Satfinder (с активным тюнером)
🔵 СИНЯЯ	Открыть мини-скин
OK / EXIT	Закрыть плагин
🎯 Мини-скин
Мини-скин открывается нажатием синей кнопки на главном экране. Он появляется по центру в верхней части экрана (как информационная панель OpenATV) и позволяет быстро проверить сигнал при переключении каналов. Использование мини-скина
Кнопка	Функция
◄ ВЛЕВО	Предыдущий канал
► ВПРАВО	Следующий канал
▲ ВВЕРХ	Открыть список каналов
▼ ВНИЗ	Открыть список каналов
OK	Закрыть мини-скин
EXIT	Закрыть мини-скин
BLUE	Закрыть мини-скин
Автоматизация мини-скина
🕐 Автоматическое закрытие через 15 секунд бездействия
🔄 Сброс таймера при каждой смене канала (остается открытым в процессе переключения)
⚡ Мгновенное обновление при смене канала (немедленно + 300 мс + 800 мс)
🎯 Автоматическое обновление всех параметров: пикон, название канала, SNR, AGC, дБ, технические характеристики

Что отображает мини-скин
Для DVB-S/S2:

Для DVB-C/C2:
