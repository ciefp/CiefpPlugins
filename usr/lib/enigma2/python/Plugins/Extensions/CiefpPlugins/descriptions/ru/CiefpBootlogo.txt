🚀 CiefpBootlogo v1.1 для Enigma2
CiefpBootlogo — это легкий, быстрый и удобный плагин для Enigma2, разработанный для простой смены загрузочного логотипа вашей телеприставки.
Он полностью обходит ограничения ресурсоемких локальных преобразований видео и кодировщика FFmpeg,
предлагая мгновенную установку как из онлайн-репозитория GitHub, так и из локального хранилища /tmp со встроенным автоматическим резервным копированием и восстановлением.

✨ Ключевые особенности и нововведения в версии 1.1
Автоматическое резервное копирование системы: автоматически создает резервные копии ваших оригинальных загрузочных логотипов системы (.backup) перед применением новых, гарантируя нулевой риск.
Восстановление в один клик (желтая клавиша): мгновенно восстанавливайте исходный резервный загрузочный логотип в любое время.
Мгновенная интеграция с GitHub: прямой онлайн-просмотр и предварительный просмотр доступных загрузочных логотипов.

Установка в один клик: Загружает предварительно созданные файлы загрузочного логотипа .mvi и автоматически обновляет все системные расположения (bootlogo.mvi, backdrop.mvi, bootlogo_wait.mvi).
Высокая производительность: Молниеносная работа без нагрузки на процессор и зависимости от системных кодировщиков FFmpeg.
Поддержка локальных MVI: Быстрая установка пользовательских локальных файлов .mvi непосредственно из каталога /tmp.
Современный пользовательский интерфейс: Чистый дизайн Full HD с графическим предварительным просмотром в реальном времени.

🎮 Как использовать
🌐 1. Онлайн-режим (репозиторий GitHub)
Откройте CiefpBootlogo из меню плагинов.
Просмотрите доступный список слева, используя клавиши навигации ВВЕРХ/ВНИЗ.
Проверьте визуальный предварительный просмотр в реальном времени справа.
Нажмите кнопку OK или ЗЕЛЕНУЮ кнопку, чтобы загрузить и применить выбранный загрузочный логотип.

📁 2. Локальный режим (папка /tmp)
Скопируйте свой пользовательский файл .mvi в каталог /tmp на вашем ресивере (через FTP/SFTP).
Откройте плагин и нажмите СИНЮЮ кнопку (Изменить источник).

Выберите Локальный источник (/tmp).
Выделите свой локальный файл .mvi из списка и нажмите ОК или ЗЕЛЕНУЮ кнопку для применения.

🔄 3. Восстановление оригинального логотипа загрузки
Нажмите ЖЕЛТУЮ кнопку в любое время, чтобы восстановить оригинальный логотип загрузки системы из автоматической резервной копии.

🔘 Ярлыки дистанционного управления
🔴 КРАСНЫЙ: Выход из плагина
🟢 ЗЕЛЕНЫЙ / ОК: Загрузка и применение выбранного логотипа загрузки
🟡 ЖЕЛТЫЙ: Восстановление оригинального резервного логотипа загрузки
🔵 СИНИЙ: Переключение источника (GitHub / Локальный / временный)
