📺 ОПИСАНИЕ

CiefpChannelHistory — это плагин для Enigma2, который отслеживает
историю просмотра телеканалов и предоставляет подробную статистику,
включая экран информации EPG в формате FHD, дополненный данными
с сервисов TMDB и OMDb.

Идея создания этого плагина возникла на основе двух предыдущих разработок:
• CiefpTMDBinfo
• CiefpEPGinfo

Объединение функционала этих двух плагинов привело к созданию
CiefpChannelHistory — комплексного инструмента для отслеживания
и анализа привычек просмотра телеканалов.

📊 ВАЖНОЕ ПРИМЕЧАНИЕ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Для получения максимально точной и достоверной статистики
плагину требуется некоторое время на сбор данных.

Плагин начинает отслеживать просмотры сразу после установки.
Чем дольше вы используете плагин, тем точнее становится статистика:

• Первый день    → базовая статистика (по нескольким каналам)
• 3–5 дней      → реалистичная картина просмотров
• 7+ дней       → надежная статистика по часам и дням
• 30+ дней      → полный анализ привычек просмотра

Мы рекомендуем использовать плагин без очистки базы данных
в течение как минимум 3–5 дней, прежде чем делать выводы
о своих привычках просмотра.

Статистика сохраняется в базе данных SQLite и не теряется
при перезапуске Enigma. Вы можете удалить данные через меню
«Настройки» → «Очистить всю историю» (Settings → Clear All History),
если захотите начать сбор статистики с нуля. 🎯 ОСНОВНЫЕ ФУНКЦИИ

▶ История просмотра каналов
• Автоматическое отслеживание всех просматриваемых каналов
• Запись длительности, количества просмотров и времени последнего просмотра
• Использование базы данных SQLite с режимом WAL для надежности

▶ Главный экран FHD (1920x1080)
• Список из 15 последних каналов (история)
• Отображение текущего канала в верхней части
• Информация EPG + постер TMDB + актерский состав
• Пиконы (логотипы) каналов

▶ Экран информации EPG в формате FHD (желтая кнопка)
• Список событий EPG для выбранного канала
• Подробная информация с TMDB (постер, жанр, режиссер, описание)
• Рейтинг IMDb
• Актерский состав и съемочная группа с фотографиями
• Просмотр фильмографии
• Воспроизведение трейлеров через yt-dlp

▶ Статистика (зеленая кнопка)
• Общий обзор: количество каналов, сеансов, общее время
• Топ-20 каналов: самые просматриваемые каналы
• По типу сервиса: DVB-S, DVB-T, IPTV
• По спутникам: более 20 спутников с названиями
• По типу кодировки: FTA, Irdeto, NDS, Nagravision...
• По времени суток: часы пиковой активности
• По дням недели: сравнение будней и выходных
• Типичный просмотр: что вы обычно смотрите в это время

▶ Определение спутника
• Считывание namespace из service reference
• Сопоставление с названием спутника из файла satellites.xml
• Поддержка DVB-S, DVB-T, DVB-C
• Отображение позиции и названия (например, "23.5E (Astra 3C)")

▶ Определение CAID
• Считывание активных CAID из service.info()
• Считывание активного CAID из /tmp/ecm.info
• Отображение информации обо всех CAID с названиями систем
• Поддержка: Irdeto, NDS, Nagravision, Conax,
Cryptoworks, Viaccess, Seca, PowerVu, Biss...

▶ Фильтр контента для взрослых (родительский контроль)
• Считывание черного списка из /etc/enigma2/blacklist
• Пропуск каналов для взрослых в Статистика
• Опционально: Вкл./Выкл. в настройках
• Автоматическое обновление при изменении настроек родительского контроля

▶ Экран настроек (синяя кнопка)
• Папка базы данных (HDD/USB/tmp)
• Размер истории (10–50)
• Мин. время просмотра (5–300 с)
• Задержка регистрации (Debounce) (3–60 с)
• Срок хранения истории (30/60/90/180/365 дней / Бессрочно)
• Фильтр контента для взрослых (родительский контроль): Да/Нет
• API-ключи: TMDB, OMDb, GROQ
• Показывать рейтинг IMDB: Да/Нет
• Загружать постеры: Да/Нет
• Язык: 9 языков
• Очистка старых сессий
• Очистка кэша
• Очистка всей истории
• Ручное обновление

💡 ТРЕБОВАНИЯ
-

• Имидж Enigma2 (протестировано на OpenATV 8.0)
• Python 3
• python3-sqlite3
• python3-requests
• API-ключ TMDB (бесплатно: https://www.themoviedb.org/settings/api)
• API-ключ OMDb (бесплатно: https://www.omdbapi.com/apikey.aspx)
• API-ключ GROQ (бесплатно: https://console.groq.com/keys)


⚙️ КАК ПОЛУЧИТЬ API-КЛЮЧИ
-

1) API-ключ TMDB
• Зарегистрируйтесь на сайте https://www.themoviedb.org/
• Перейдите в Settings (Настройки) → API → Request API Key (Запросить API-ключ)
• Скопируйте API-ключ

2) API-ключ OMDb
• Перейдите на страницу https://www.omdbapi.com/apikey.aspx
• Выберите Free (лимит 1000 запросов в день)
• Скопируйте API-ключ из полученного письма

3) Введите ключи в плагин:
• Откройте CiefpChannelHistory
• Синяя кнопка (Настройки)
• TMDB API Key → OK → введите ключ
• OMDb API Key → OK → введите ключ
• GROQ: API key → OK → введите ключ
• Сохранить (зеленая кнопка)

- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/groqapikey.txt

Главный экран:
• Вверх/Вниз    — список каналов
• OK            — переключиться на канал
• Зеленая       — Статистика
• Желтая        — Информация EPG
• Синяя         — Настройки
• Красная       — Выход

Экран информации EPG:
• Вверх/Вниз    — список событий EPG
• Зеленая       — Фильмография
• Желтая        — Актерский состав
• Синяя         — Трейлер
• OK            — Переключить канал
• BACK          — Назад

Статистика:
• Вверх/Вниз    — Категории
• Зеленая       — Обновить


🔧 ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• База данных SQLite с режимом WAL
• Периодическое обновление сеанса (макс. потеря данных 30 с при перезапуске)
• Опрос состояния (polling) каждые 5 с для отслеживания смены каналов
• Задержка обработки (debounce) 10 с (предотвращает ложные сеансы)
• Минимальное время просмотра 30 с (канал должен просматриваться не менее 30 с)
• Автоматическая очистка старых сеансов (хранение данных)
• Многопоточность для всех сетевых операций
• Интерфейс (скин) FHD 1920x1080
