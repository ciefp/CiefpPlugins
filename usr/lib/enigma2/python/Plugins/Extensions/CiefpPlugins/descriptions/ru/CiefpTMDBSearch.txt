🖼️ Краткая инструкция: Как использовать средство просмотра постеров и фонов
Новая галерея проста в использовании. Вот краткое руководство:

Доступ к галерее:
После загрузки данных о фильме или сериале нажмите кнопку MENU на пульте дистанционного управления.

В меню выберите пункт 🖼️ Галерея фонов или 🎬 Галерея постеров.

Навигация по галерее:
Используйте ЖЕЛТЫЕ и СИНИЕ кнопки (или стрелки влево/вправо) для перемещения по изображениям.

ЗЕЛЕНАЯ кнопка возвращает вас на главный экран или переключает между фоновой галереей и галереей постеров (если она доступна).
Строка состояния вверху показывает, какое изображение вы просматриваете (например, «6/185»).

Закрытие галереи:
Нажмите КРАСНУЮ кнопку или кнопку ОК/Выход, чтобы вернуться на главный экран плагина.

💡 Советы и примечания
Кэширование: Изображения автоматически загружаются и сохраняются в выбранную вами папку кэша (настраивается в настройках). Это ускоряет их отображение при следующем открытии.
Языковые настройки: В настройках вы можете изменить язык описаний (язык). Это также влияет на язык данных, получаемых из базы данных TMDB.

Производительность: Если плагин начинает работать медленно из-за переполнения кэша, вы можете очистить его через МЕНЮ > Дополнительные параметры > 🗑️ Очистить кэш.

..:: CiefpTMDBSearch v1.0 ::..

Поиск фильмов и сериалов на TMDB с постерами, описаниями, актерами и рейтингами — на 14 языках!
Требуется только бесплатный ключ API TMDB (вводится один раз с помощью желтой кнопки).

# ОСНОВНЫЕ ФУНКЦИИ #
Поиск фильмов (ЗЕЛЕНЫЙ) и сериалов (ЖЕЛТЫЙ)
Отображение подробной информации: название, год, продолжительность, рейтинг, жанр, режиссер/создатель, актеры, описание
Загрузка постера (обложки) с TMDB
Поддержка нескольких языков (описание, названия)
Кэширование постеров (более быстрый доступ, меньший интернет-трафик)
Ручная настройка ключа API TMDB

# УСТАНОВКА И НАСТРОЙКА #
1. Ключ API (ОБЯЗАТЕЛЬНО)
Зарегистрируйтесь на themoviedb.org и получите ключ API
В плагине нажмите СИНИЙ → Настройки → ЖЕЛТЫЙ (Ключ API)
Введите свой ключ API с помощью виртуальной клавиатуры

2. Ключ API хранится в файле tmdbapikey.txt
Вы можете ввести ключ в текстовый файл tmdbapikey.txt
и перенести его в папку плагина
при запуске плагина он будет его считывать. # ИСПОЛЬЗОВАНИЕ #
Главное меню:
ЗЕЛЕНЫЙ → Поиск фильмов
ЖЕЛТЫЙ → Поиск сериалов
СИНИЙ → Настройки
СТРОКА → Выход

Пример поиска:
Нажмите ЗЕЛЕНЫЙ для фильмов
Введите название фильма (например, «Начало»)
Плагин отобразит:
Название, год, продолжительность
Рейтинг (например, 8.3/10 ★)
Жанр, режиссер
Краткое описание сюжета
Главные актеры
Постер (если есть)

# НАСТРОЙКИ (СИНИЙ) #
Ключ API (ЖЕЛТЫЙ) - установите свой ключ
Язык (СИНИЙ) - измените язык
Скачать постеры - включить/отключить загрузку постеров
Очистить кэш (МЕНЮ) - очистить все сохраненные постеры
Сохранить (ЗЕЛЕНЫЙ) - сохранить изменения

# КЭШИРОВАНИЕ #
Постеры автоматически сохраняются в /tmp/CiefpTMDBSearch/
Экономит интернет-трафик при повторных запросах поиск
При желании вы можете отключить его в настройках.

# ПОДДЕРЖИВАЕМЫЕ ЯЗЫКИ #
Английский, Сербский, Хорватский, Боснийский, Словацкий, Немецкий, Испанский,
Французский, Итальянский, Русский, Португальский, Польский, Турецкий, Арабский, Китайский.

Протестировано и отлично работает на:
OpenATV · OpenBH · OpenPLI · Pure2 · Egami · OpenVision

Что нового в версии 1.7
В меню расширенного поиска добавлены четыре новых параметра:

Поиск популярных фильмов
– Отображает 20 самых популярных фильмов на данный момент на TMDB (долгосрочная популярность).

– Список содержит: название фильма, год выпуска, рейтинг TMDB и количество звезд.

– При нажатии на фильм открывается полная версия с постером, описанием, актерами и т. д.
Поиск популярных сериалов
– Отображает 20 самых популярных сериалов на данный момент на TMDB.

– Отображает: название сериала, год начала, рейтинг и количество звезд.

– При выборе открывается подробная информация о сериале.
Поиск популярных людей
– Отображает 20 самых популярных людей (актеров, режиссеров и т. д.).

– Отображает: имя человека, область (например, актерская/режиссурная деятельность), краткий список известных фильмов/сериалов, популярность с указанием количества звезд.

- Нажмите, чтобы открыть профиль человека с биографией, фильмографией и постером.
Поиск трендов Все (Ежедневно)
– Отображает 20 самых актуальных названий и людей за день (смешанные – фильмы, сериалы и люди),
как раздел «Тренды» на главной странице TMDB.

– Обновляется ежедневно и показывает, что сейчас наиболее популярно (новые хиты, вирусные сериалы, актуальные актеры).

– Отображается:
• Фильмы: [Фильм] Название (год) ★★★★★ 7.8
• Сериалы: [Сериал] Название (год) ★★★★★ 8.5
• Люди: [Человек] Имя Фамилия • Актерская карьера ★★★★ 45.2
– Выбор открывает соответствующее подробное представление (фильм/сериал/профиль человека).

Остальные

Для скорости и четкости отображения все результаты ограничены 20 (как на сайте TMDB — первая страница).
Рейтинги отображаются звездочками для более быстрого просмотра.
Поддерживается выбор языка описания (через настройки плагина).
