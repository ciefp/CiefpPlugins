📺 CiefpXfiles – IPTV plugin typu Xtream pre Enigma2
CiefpXfiles je pokročilý IPTV plugin pre Enigma2 (Python 3), ktorý umožňuje sledovať streamy Xtream Codes prostredníctvom prehľadného FHD rozhrania.
Ponúka automatické sťahovanie plagátov a popisov z databáz TMDB/OMDb, ako aj preklad popisov do srbčiny pomocou umelej inteligencie GROQ AI.

Tento plugin je výsledkom rozsiahlej práce zameranej na optimalizáciu, stabilitu a predovšetkým na vizuálny zážitok.
Dôraz bol kladený na FHD rozhranie, vysoký výkon a automatické obohacovanie obsahu (plagáty, popisy, hodnotenia).
Plugin vznikol zlúčením niekoľkých mojich predchádzajúcich doplnkov do jedného celku:
- Integrácia s TMDB/OMDb (vychádza z pluginu CiefpTMDBsearch).
- Pripojenie k portálom (vychádza z pluginu CiefpE2Converter).
- Preklad popisov deja pomocou API kľúča GROQ (vychádza z pluginu CiefpEPGinfo).
Veľká zásluha na realizácii týchto myšlienok patrí umelej inteligencii „Deepseek“,
ktorá mi pomohla naplniť moju víziu a špecifické požiadavky.

✨ Kľúčové vlastnosti
Podpora pre Xtream Codes a M3U – Stačí zadať zoznam skladieb (playlist) alebo prihlasovacie údaje k službe Xtream.
FHD rozhranie – Moderný dizajn s tromi panelmi (kategórie, informácie, plagát).
Integrácia s TMDB a OMDb – Automaticky zobrazuje plagáty, popisy, obsadenie, režisérov a hodnotenia z IMDb.
Preklad pomocou GROQ AI – Automaticky prekladá popisy filmov do srbčiny (alebo iného jazyka).
Vyhľadávanie – Rýchle vyhľadávanie filmov a seriálov podľa názvu (pomocou tlačidla INFO).
Stav portálu – Zelené/červené indikátory pre online/offline servery. Automatické aktualizácie – Plugin vás upozorní, keď bude k dispozícii nová verzia.
Systémový priečinok – Všetky dáta sú uložené v adresári /etc/enigma2/CiefpXfiles/.

⚙️ Konfigurácia
Po inštalácii otvorte plugin z ponuky (menu). Pri prvom použití bude potrebné zadať vaše API kľúče.
Stlačte tlačidlo MENU (alebo zvoľte SETTINGS v spodnej časti obrazovky). Zadajte nasledujúce kľúče:
API kľúč TMDB — K dispozícii bezplatne na stránke themoviedb.org. -- (tmdbapikey.txt)
API kľúč OMDb — K dispozícii bezplatne na stránke omdbapi.com. -- (omdbapikey.txt)
API kľúč GROQ — K dispozícii bezplatne na stránke console.groq.com. -- (groqapikey.txt)
API kľúč SUBDL — Voliteľný, pre titulky. -- (subdlapikey.txt)
API kľúč SUBDL sa momentálne nepoužíva, je však zahrnutý v rámci prípravy na budúce verzie.

Umiestnenie pre API kľúče: /etc/enigma2/CiefpXfiles/keys/
Nakonfigurujte jazyk titulkov, typ prehrávača a ďalšie možnosti.
Stlačte zelené tlačidlo (Uložiť). 📂 Umiestnenie a súbory:
/etc/enigma2/CiefpXfiles/
playlist.txt
portals_cache.json
/etc/enigma2/CiefpXfiles/keys/
tmdbapikey.txt, omdbapikey.txt, groqapikey.txt, subdlapikey.txt
/etc/enigma2/CiefpXfiles/posters/
/etc/enigma2/CiefpXfiles/subtitles/
/etc/enigma2/CiefpXfiles/epg/

📂 Nová štruktúra súborov (Bezpečnosť):
Všetky vaše údaje (API kľúče, vyrovnávacia pamäť plagátov, zoznamy skladieb) sú teraz uložené na bezpečnom mieste: /etc/enigma2/CiefpXfiles/.
To znamená, že pri aktualizácii alebo preinštalovaní doplnku (pluginu) zostanú vaše kľúče a zoznamy zachované. 📁 Playlist.txt
Do zoznamu skladieb (playlistu) môžete pridávať položky dvoma spôsobmi:

Formát A (Štruktúrovaný)
text
Host:http://server:port
Používateľské meno: xxxx
Heslo: xxxx
m3u:http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
EPG: http://server:port/xmltv.php?username=xxxx&password=xxxx

Formát B (Iba odkazy M3U)
text
http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
http://server:port/xmltv.php?username=xxxx&password=xxxx
Súbor playlist.txt sa nachádza v priečinku /etc/enigma2/CiefpXfiles/playlist.txt.

🎮 Skratky na diaľkovom ovládači
Tlačidlo	Funkcia
OK	Otvoriť kategóriu / Spustiť stream
EXIT	Zavrieť plugin
Zelené	Živé vysielanie (Live TV)
Žlté	Filmy
Modré	Seriály
MENU	Nastavenia
INFO	Vyhľadávanie


🛠️ Technické podrobnosti
Python: 3
Podporované image-e: OpenATV, OpenPLi, OpenViX, OpenBH, Pure2, EGAMI
Prehrávače: Exteplayer3 (5002), GStreamer (5001), GStreamer (4097)
Vyrovnávacia pamäť (Cache): /etc/enigma2/CiefpXfiles/ (plagáty, EPG, kľúče)
