Python 2.7 ή Python 3.x

Προτεινόμενες απαιτήσεις

Επεξεργαστής: 600 MHz ή ταχύτερος (για ταχύτερη φόρτωση και επεξεργασία yt-dlp)
Εσωτερική μνήμη: 50 MB ελεύθερος χώρος

📦 Εξαρτήσεις
Περιγραφή εξαρτήσεων
Python 3.x (ενσωματωμένο στο Enigma2)
enigma2 Core framework (ενσωματωμένο)
json Για ρυθμίσεις (ενσωματωμένο)
υποδιεργασία Για εκτέλεση εξωτερικών εργαλείων (ενσωματωμένο)

Προαιρετικές εξαρτήσεις (απαιτούνται για την υποστήριξη του YouTube)
Εξάρτηση Έκδοση Περιγραφή
yt-dlp 2023.11.16 ή νεότερη έκδοση Για εξαγωγή ροών YouTube
ffmpeg 4.0 ή νεότερη έκδοση Για επεξεργασία ροών βίντεο/ήχου
Εγκατάσταση προαιρετικών εξαρτήσεων
bash
# Μέσω opkg (OpenATV, OpenPLi, κ.λπ.)
opkg update
opkg install yt-dlp ffmpeg

# Ή χειροκίνητα μέσω pip
pip install yt-dlp

# Επαλήθευση εγκατάστασης
yt-dlp --version
ffmpeg -version
ΣΗΜΕΙΩΣΗ: Χωρίς yt-dlp και ffmpeg, οι σύνδεσμοι YouTube ΔΕΝ ΘΑ λειτουργήσουν. Οι ροές m3u8 λειτουργούν χωρίς αυτά.

Υποστήριξη py2 & py3
Το WebCamE2PrenjSF είναι ένα απλό πρόσθετο Enigma2 που επιτρέπει γρήγορη λήψη και εγκατάσταση του τελευταίου μπουκέτου χρηστών με κάμερες web απευθείας από το αποθετήριο GitHub.

- Ελέγχει αυτόματα την έκδοση του μπουκέτου και κατεβάζει την πιο πρόσφατη εάν υπάρχει νεότερη από την εγκατεστημένη.

- Το εγκατεστημένο μπουκέτο αποθηκεύεται στο /etc/enigma2/ και καταχωρείται στο bouquets.tv.

- Μετά την εγκατάσταση, προσφέρει την επιλογή αυτόματης επαναφόρτωσης της λίστας καναλιών.
- Είναι πολύ εύκολο στη χρήση - εκτελέστε το πρόσθετο και πατήστε OK.

Το πρόσθετο προορίζεται για όλους όσους θέλουν να έχουν πάντα μια ενημερωμένη λίστα με κάμερες web
στον δέκτη Enigma2 χωρίς να αντιγράφουν αρχεία χειροκίνητα.

Το πρόσθετο δημιουργήθηκε με τις κοινές προσπάθειες του Prenj και του Ciefp Satellite Forum (SF)
