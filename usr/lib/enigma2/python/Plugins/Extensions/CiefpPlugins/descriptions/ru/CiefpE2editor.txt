Описание плагина CiefpE2editor

Это мой 40-й плагин, созданный в сотрудничестве с искусственным интеллектом.

Описание: CiefpE2editor — это мощный, всеобъемлющий инструмент Enigma2, разработанный полностью в разрешении Full HD (1920x1080).
Вдохновленный легендарной программой для ПК Dreamboxedit, этот плагин обеспечивает расширенное управление каналами,
букетами и транспондерами непосредственно на вашем ресивере, устраняя необходимость в компьютере.
Плагин объединяет несколько мощных модулей в едином графическом интерфейсе,
позволяя полностью контролировать базу данных lamedb и списки пользователей без необходимости в компьютере.

🚀 Основные функции и возможности
1. Главный редактор с тремя панелями (главный экран)
Обзор в одном месте: Экран разделен на три функциональные панели высокого разрешения (FHD):
Сервис (Все каналы из lamedb), Каналы (Каналы в активном букете) и Букеты (Список ваших букетов).

1. Главный редактор (CiefpE2editorMain)
Тройной вид панели:
Слева: Список всех сервисов (каналов)
Посередине: Каналы в активном пакете
Справа: Лист пакета

Фильтры каналов:
По спутнику (все спутники, отдельные спутники, наземные)
По типу (ТВ, Радио)
По разрешению (SD, HD H.264, HD H.265, UHD)
По провайдеру
Новые каналы (флажок X)

Управление каналами:
Копирование каналов в активный пакет
Удаление каналов из списка
Сохранение и перезагрузка настроек
2. Редактор каналов (CiefpChannelEditor)
Перемещение/удаление каналов
Выбор групп каналов под маркером
Перемещение каналов вверх/вниз (перетаскивание)
Сохранение изменений в пакете
3. Редактор пакетов (CiefpBouquetEditor)
Управление пакетами (создание, удаление, перемещение)
Открыть Редактор каналов для выбранного пакета

4. Менеджер каналов (CiefpChannelManager)
Загрузка настроек из GitHub
Копирование и установка пакетов
Автоматическая загрузка последних списков

5. Загрузчик настроек (CiefpSettingsDownloaderScreen)
Загрузка готовых списков каналов из репозитория GitHub
Поддерживает более 15 различных комбинаций спутников:
От 1 спутника (19E) до 18 спутников
Охватывает все популярные спутники: 42E, 39E, 28E, 23E, 19E, 16E, 13E, 9E, 0.8W, 4W, 5W, 30W и т. д.
Диапазон моторизованных списков каналов: 80.0E - 34.0W

6. Селектор спутников (CiefpSelectSatellite)
Выбор спутников для установки
Автоматическое сопоставление спутников с соответствующими файлами пакетов
Копирование и установка выбранных спутники
Поддерживает более 40 различных положений спутников

7. Редактор Satellites.xml (CiefpSatelliteXmlReader/Editor)
Просмотр и редактирование файла satellites.xml
Добавление и удаление транспондеров
Редактирование всех параметров транспондера:
Частота, Символьная скорость
Поляризация, FEC
Система DVB-S/S2
Модуляция (QPSK, 8PSK, 16APSK, 32APSK)
Многопотоковая передача (IS, режим/код PLS)
Поддержка T2-MI

8. Белый список Streamrelay (WhitelistScreen)
Создание файла whitelist_streamrelay
Автоматический анализ букета каналов Streamrelay
Фильтр для исключения нежелательных ссылок
