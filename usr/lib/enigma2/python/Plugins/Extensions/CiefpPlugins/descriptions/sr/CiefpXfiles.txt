📺 CiefpXfiles - Xtream IPTV Plugin za Enigma2
CiefpXfiles je napredni IPTV plugin za Enigma2 (Python 3) koji vam omogućava gledanje Xtream Codes strimova sa prelepim FHD interfejsom, 
automatskim preuzimanjem postera i opisa sa TMDB/OMDb, i prevodom opisa na srpski putem GROQ AI.

Plugin je rezultat dugog rada na optimizaciji, stabilnosti i pre svega - vizuelnom iskustvu. 
Fokus je stavljen na FHD interfejs, brzinu rada i automatsko obogaćivanje sadržaja (posteri, opisi, ocene).
Plugin nastaje spajanjem više mojih plugina u jedan novi plugin:
- Inegracija sa tmdb omdb ideja iz plugina CiefpTMDBsearch
- spajanje na portale ideja iz plugina CiefpE2Converter
- prevod opisa "Plot" koristeći groq api ključ ideja iz CiefpEPGinfo
Velike zasluge za ostvarivanje mojih ideja je zaslužan A.I. Deepseek 
koji mi je pomogao u ostvarivanju mojih vizija i zahteva.

✨ Glavne funkcije
Podrška za Xtream Codes i M3U — Unesite playlistu ili Xtream kredencijale.
FHD interfejs — Moderan dizajn sa 3 panela (kategorije, informacije, poster).
TMDB i OMDb integracija — Automatski prikaz postera, opisa, glumaca, režisera i IMDb ocena.
GROQ AI prevod — Automatski prevod opisa filmova na srpski (ili drugi jezik).
Pretraga — Brza pretraga filmova i serija po nazivu (dugme INFO).
Status portala — Zeleni/crveni indikatori za online/offline servere.
Automatski update — Plugin vas obaveštava kada je dostupna nova verzija.
Sistemski folder — Svi podaci se čuvaju u /etc/enigma2/CiefpXfiles/.

⚙️ Podešavanje
Nakon instalacije, otvorite plugin iz menija. Prvi put ćete morati da unesete API ključeve.
Pritisnite MENU (ili SETTINGS na dnu ekrana).

Unesite sledeće ključeve:
TMDB API Key — Besplatno na themoviedb.org.   -- (tmdbapikey.txt)
OMDb API Key — Besplatno na omdbapi.com.      -- (omdbapikey.txt)
GROQ API Key — Besplatno na console.groq.com. -- (groqapikey.txt)
SUBDL API Key — Opciono, za titlove.          -- (subdlapikey.txt)
subdl api key se ne koristi trenutno ali priprema za buduće verzije

lokacija za apiključeve /etc/enigma2/CiefpXfiles/keys/
Podesite jezik prevoda, tip plejera i ostale opcije.
Kliknite Zeleno (Save).

📂 Nova struktura fajlova (Sigurnost):
Svi vaši podaci (API ključevi, keš postera, playliste) sada se čuvaju na sigurnoj lokaciji: /etc/enigma2/CiefpXfiles/.
To znači da kada radite update ili reinstalaciju plugina, vaši ključevi i liste ostaju sačuvani.


📁 Playlist.txt
Playlistu možete dodati na dva načina:

Format A (strukturirani)
text
Host:http://server:port
Username:xxxx
Password:xxxx
m3u:http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
EPG:http://server:port/xmltv.php?username=xxxx&password=xxxx

Format B (samo M3U linkovi)
text
http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
http://server:port/xmltv.php?username=xxxx&password=xxxx
Fajl playlist.txt se nalazi u /etc/enigma2/CiefpXfiles/playlist.txt.
