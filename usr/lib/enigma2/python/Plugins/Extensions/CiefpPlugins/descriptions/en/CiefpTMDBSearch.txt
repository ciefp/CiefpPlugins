Gallery access:

Navigation through the gallery:
Use the YELLOW and BLUE buttons (or left/right arrows) to move through the images.

..:: CiefpTMDBSearch v1.0 ::..

Search movies and series through TMDB with posters, descriptions, actors and ratings - in 14 languages!
Only a free TMDB API key is required (entered once via the yellow button).

# BASIC FUNCTIONS #
Search for movies (GREEN) and series (YELLOW)
Display details: title, year, duration, rating, genre, director/creator, actors, description
Downloading the poster (cover) from TMDB
Support for multiple languages ​​(description, titles)
Poster caching (faster access, less internet traffic)
Manually setting the TMDB API key

# INSTALLATION AND SETUP #
1. API Key (MANDATORY)
Register at themoviedb.org and get an API key
In the plugin, press BLUE → Settings → YELLOW (API Key)
Enter your API key via the virtual keyboard

2. The API key is stored in tmdbapikey.txt
You can enter the key in the text file tmdbapikey.txt
and transfer it to the plugin folder
when starting the plugin will read it.

# USAGE #
Main menu:
GREEN → Search movies
YELLOW → Series search
BLUE → Settings
ROW → Exit

Search example:
Press GREEN for movies
Enter the name of the movie (eg "Inception")
The plugin displays:
Title, year, duration
Rating (eg 8.3/10 ★)
Genre, director
Short description of the plot
The main actors
Poster (if available)

# SETTINGS (BLUE) #
API Key (YELLOW) - set your key
Language (BLUE) - change the language
Download Posters - enable/disable download of posters
Clear Cache (MENU) - clear all saved posters
Save (GREEN) - save changes

# CACHING #
Posters are automatically saved in /tmp/CiefpTMDBSearch/
Saves internet traffic during repeated searches
You can turn it off in the settings if you want

# SUPPORTED LANGUAGES #
English, Serbian, Croatian, Bosnian, Slovak, German, Spanish,
French, Italian, Russian, Portuguese, Polish, Turkish, Arabic, Chinese.

Tested and works perfectly on:
OpenATV · OpenBH · OpenPLI · Pure2 · Egami · OpenVision

The best TMDB info plugin for Enigma2
Now with automatic EPG search!
Get all information about the movie/series (poster, rating, cast, plot, etc.) right now.
directly on your Enigma2 receiver - no phone or computer needed!
What's new in v1.2

Automatic EPG search (BLUE button) – just press the BLUE button while watching any channel
and the plugin will automatically download the current program title/year from the EPG and search the TMDB!
Smart title cleaning (removes [HD], (2024), Movie:, etc.)
It tries both movie → series and series → movie until it finds the correct result
Much better detection of the year from the EPG description
Faster and more reliable downloading and caching of posters
15 languages ​​supported (including Serbian, Croatian, Bosnian, English, German, etc.)

Characteristics

Beautiful large poster (500×750) + all details on one screen
Full cast list with character names
Director / Creators, Genres, Running Time, Rating ★
Poster caching (/tmp or HDD) - lightning fast after first download
Clear cache option + cache information
Works perfectly on all modern Enigma2 images (OpenATV, OpenBH, VTI, BlackHole, Egami, etc.)

How to use

Install the plugin
First boot → press MENU → Settings → YELLOW button → enter your free TMDB API key
(download it in 10 seconds here: https://www.themoviedb.org/settings/api)
Launch the add-on from the menu

Buttons

GREEN – Manual search for movies
YELLOW – Manual search for series
BLUE – Automatic search for current EPG event ← NEW AND AWESOME!
MENU – Settings (language, cache folder, poster deletion…)

What's new in version 1.7
Four new options have been added to the Advanced Search menu:

Search popular Movies
– Shows the 20 most popular movies currently on TMDB (long term popularity).
– The list contains: movie name, year of release, TMDB rating and stars.
- Clicking on the film opens a full view with the poster, description, actors, etc.
Search popular Series
– Shows the 20 most popular series currently on TMDB.
– Display: name of series, year of start, rating and stars.
– Selection opens a detailed view of the series.
Search popular persons
– Shows the 20 most popular people (actors, directors, etc.).
– Display: person's name, field (eg Acting/Directing), short list of famous movies/series, popularity with stars.
- Click to open the person's profile with biography, filmography and poster.
Search trending All (Daily)
– Shows the 20 most current titles and people per day (mixed – movies, series and people), 
just like the "Trending" section on the TMDB home page.
- It is updated daily and shows what is currently most in focus (new hits, viral series, current actors).
– Display:
• Movies: [Mov] Title (year) ★★★★★ 7.8
• Series: [Ser] Title (year) ★★★★★ 8.5
• Persons: [Person] Name Surname • Acting ★★★★ 45.2
– Selection opens the corresponding detailed view (movie/series/person profile).

The rest

All displays are limited to 20 results for speed and clarity (as on the TMDB site - first page).
Ratings are shown with stars for faster viewing.
Selection of description language is supported (via plugin settings).
Installation online via plugin
