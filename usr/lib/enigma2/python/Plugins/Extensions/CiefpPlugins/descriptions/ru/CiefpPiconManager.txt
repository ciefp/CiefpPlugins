..:: Менеджер пиконов Ciefp ::..

Менеджер пиконов Ciefp — это продвинутый плагин Enigma2 для управления пиконами (значками каналов) в OpenATV и других системах Enigma2.
Плагин позволяет легко просматривать, назначать, удалять и загружать пиконы из ленты OpenATV.


Основные функции:
Обзор букетов и каналов — левая панель отображает букеты, средняя панель — каналы
Автоматическое отображение значков — правая панель отображает значки для выбранного канала
Назначение значков — возможность назначать значки каналам из папки на USB-накопителе
Загрузка значков — напрямую из ленты OpenATV (более 42 пакетов)
Удаление значков — легко удалять назначенные значки
Поддержка подпапок — поиск по всем подпапкам в каталоге значков

Меню:
OpenATV: Меню → Плагины → Менеджер значков Ciefp
Другое: Браузер плагинов → Менеджер значков Ciefp

# Главный экран
Главный экран разделен на три панели:

Содержание панелей Навигация
Левая панель Список букетов Стрелки вверх/вниз
Средняя панель Список каналов Стрелки вверх/вниз
Правая панель Picon + информация Автоматическое отображение
Навигация:

Влево/вправо — переключение фокуса между панелями
Вверх/вниз — перемещение по списку
OK — вход в выбранный букет/канал

# Кнопки на главном экране
Цвет кнопки Функция
ВЫХОД Красный Выход из плагина
НАЗНАЧЕНИЕ ПИКОНА Зеленый Назначить пикон каналу
НАСТРОЙКИ Желтый Настройки (выберите папку USB)
УДАЛИТЬ ПИКОН Синий Удалить пикон для канала
МЕНЮ ЗАГРУЗКА Белый Скачать пикон из ленты
# Назначить пикон (НАЗНАЧИТЬ ПИКОН)
Выберите канал на главном экране
Нажмите зеленую кнопку (НАЗНАЧИТЬ ПИКОН)
Открывается таблица пиконов из папки USB

Навигация:
Вверх/вниз/влево/вправо - перемещение по таблице
ОК - назначить выбранный пикон каналу
ВЫХОД - вернуться на главный экран

# Настройки (НАСТРОЙКИ)
Нажмите желтую кнопку (НАСТРОЙКИ)
Файловый браузер для выбора папки USB:
Вверх/вниз - перемещение по списку
ОК - войти в папку
Зеленая кнопка - выбрать текущую папку
Синяя кнопка - вернуться в родительскую папку
Желтая кнопка - путь по умолчанию

# Скачать пикон (МЕНЮ)
Нажмите кнопку МЕНЮ на главном экране.
Откроет список доступных пакетов пикочков из ленты OpenATV.
Фильтры:
Слева/Справа - фильтр по типу (все, srp, utf8snp, zombie, другие)

Установка:
Выберите пакет.
Нажмите ОК для установки.
Подтвердите установку.
# Удалить пикочок (УДАЛИТЬ ПИКОНОК)
Выберите канал на главном экране.
Нажмите синюю кнопку (УДАЛИТЬ ПИКОНОК)
Плагин удалит пикочок из всех мест:

/picon/
/media/usb/picon/
