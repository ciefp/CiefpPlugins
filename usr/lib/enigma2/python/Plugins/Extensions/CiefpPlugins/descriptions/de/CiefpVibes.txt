CiefpVibes v2.2 – Versionshinweise

Neues Modul: OpenDirectory Downloader
Ein brandneues Modul zum Herunterladen von Musik von OpenDirectory-Servern wurde hinzugefügt!

Was ist OpenDirectory?

Öffentliche Server zum Teilen von Musikdateien (MP3, FLAC, M4A usw.)
Einfaches Durchsuchen und Herunterladen ohne komplizierte APIs

Funktionen:
🌐 OpenDirectory-Server durchsuchen – URLs aus der Datei opendir.txt laden
📁 Ordnernavigation – einfaches Navigieren durch Verzeichnisse
🎵 Dateiauswahl – einzelne Titel oder ganze Ordner hinzufügen
⬇️ Download-Manager – MP3-, FLAC-, M4A-, AAC-, WAV- und OGG-Dateien herunterladen

📊 Fortschrittsanzeige – Downloadfortschritt visualisieren
💾 Benutzerdefinierter Pfad – Speicherort für heruntergeladene Dateien festlegen

Anwendung:
OpenDirectory-URLs zur Datei hinzufügen:

/usr/lib/enigma2/python/Plugins/Extensions/CiefpVibes/opendir.txt
CiefpVibes starten → Online-Dateien → OpenDirectory Downloader

Navigation:
OK – Ordner auswählen / Datei hinzufügen
Blauer Button – Alles auswählen (Fügt alle Dateien aus dem Ordner hinzu)
Gelber Button – Herunterladen (lädt ausgewählte Dateien herunter)
Grüner Button – Einstellungen (Pfad festlegen)

Verbesserungen:
Automatische Bereinigung von Dateinamen (entfernt Unterstriche und doppelte Dateiendungen)
Intelligente Namensgebung (z. B. A-Ha_-_Take_On_Me.mp3 → A-Ha - Take On Me.mp3)

Protokollierung aller Download-Aktivitäten
Schnelle Auswahl aller Dateien aus einem Ordner (ohne rekursives Scannen)

Voraussetzungen:
Python 3
beautifulsoup4 (optional, für besseres Parsen)
Installation:
opkg install python3-beautifulsoup4

Kurz gesagt:
Jetzt können Sie Musik direkt von öffentlichen OpenDirectory-Servern auf Ihr Enigma2-Gerät herunterladen! 🎵

- Enigma2 Musik-Jukebox-Plugin

### Beschreibung:
CiefpVibes ist ein großartiges Musikplayer-Plugin für Enigma2-Boxen.
Spielt lokale oder Online-Playlists (.m3u/.tv) mit Wiederholung, Zufallswiedergabe,
benutzerdefinierten Hintergründen und GitHub-Integration für neue Songs ab.
Unterstützt die Formate MP3 und FLAC.

Ideal für durchgehend gute Musik!

### Bedienung: Starten Sie über das Menü „Plugins“.

Grün: Lokale Datei laden.
Blau: Online von GitHub.
Gelb: Einstellungen.
Rot: Beenden.

Durch die Playlist navigieren, OK zum Abspielen.
Speichert automatisch die letzte Sitzung.

Genieße die guten Vibes mit dem CiefpVibes Enigma2-Plugin

# CiefpVibes v1.1
Enigma2 Musik-Jukebox-Plugin

### 🆕 Neue Funktionen in Version 1.1:
Online-Radio – Unterstützung für Online-Radiosender, Möglichkeit zum Herunterladen fertiger Playlists von GitHub
Zahlreiches Cache-Verzeichnis – Alle temporären Dateien (Listen und Poster) werden jetzt in /tmp/ciefvibes_cache gespeichert
Cache leeren – Neue Option in den Einstellungen zum Löschen aller zwischengespeicherten Dateien
Cache-Größe anzeigen – Sieh dir an, wie viel Speicherplatz der Cache belegt, bevor du ihn löschst
Optimierte Dateiverwaltung – Übersichtliche Struktur für einfachere Wartung

### 🎯 Anwendung:
Grundfunktionen:
🟢 GRÜN – Dateien anzeigen (lokal)
🔵 BLAU – Online-Listen (M3U, TV, RADIO)
🟡 GELB – Einstellungen
🔴 ROT – Anwendung beenden

### Neue Option – RADIO
Drücken Sie 🔵 BLAU – Online-Listen
Wählen Sie RADIO, um verschiedene Wiedergabelisten auszuwählen.

GITHUB_RADIO_URL und Unterstützung für .radio-Dateien hinzugefügt (beim Parsen, im Dateibrowser und beim GitHub-Download).
Verbessertes Parsen von .tv-/.radio-Dateien: Erweiterte Erkennung von Audiostreams

(Kennzeichen wie .mp3, .flac, /stream, rtmp://), mit Ausnahmen für Videoformate (.ts, .mp4 usw.).
Verbessertes Metadaten-Parsing: parseArtistTitle() trennt das Format „Interpret – Titel“.
Unterstützung für ICY-Metadaten, automatische Aktualisierung des Wiedergabetextes und der Poster.

### Neue Option – Cache leeren:
Drücken Sie 🟡 GELB (Einstellungen).
Wählen Sie „🧹 Cache leeren“.

Bestätigen Sie die Löschung im Dialogfeld.
Der Cache wird geleert (Poster + Listen).

### Verbesserungen bei Optik und Wiedergabe:

- Dynamische Posteranzeige hinzugefügt (showPoster(), showDefaultPoster())

mit automatischem Download des Albumcovers von der iTunes-API (fetchAlbumCover()).

- Zwei Fortschrittsbalken: „progress_real“ (exakter Fortschritt) und „progress_vibe“ (pulsierender grüner Balken für den „Vibe“-Effekt).

- Offline-Erkennung: Bezeichnung für „offline_status“ (z. B. „Stream offline“),
Timer zur Überprüfung des Streams (checkStreamStatus()), Status wird beim Abspielen zurückgesetzt.

- Mehr Designoptionen: Bis zu 10 Hintergründe, Poster und Infoleisten (in Version 1.0 nur bis zu 5).

- Automatische Wiedergabe des ersten Titels der Willkommens-Playlist.

### Weitere Optionen in den Einstellungen:

▶ Wiedergabe – Wiederholung, Zufallsreihenfolge
🌐 Netzwerk – Timeouts, URL-Laden
🎨 Hintergrundbild – 10 Hintergrundbilder
🖼️ Poster – 10 Poster
📊 Infoleiste – 10 Infoleisten
💾 Speichern & Laden – Einstellungen speichern

### 💾 Gespeichert wird:
Poster – Albumcover (zwischengespeichert)

Einstellungen – Konfiguration in /etc/enigma2/ciefvibes.cfg
Letzte Liste – In /etc/enigma2/ciefvibes_last.txt

🔗 ANLEITUNG ZUM HERSTELLEN EINER NETZWERKVERBINDUNG
1. VORGEHENSWEISE AUF DEM LAPTOP/COMPUTER:

Für Windows:
bash
1. Rechtsklick auf den Ordner → „Eigenschaften“
2. Registerkarte „Freigabe“ → „Erweiterte Freigabe“
3. ✅ Freigeben Sein Ordner
4. „Berechtigungen“ → „Jeder“ hinzufügen → Vollzugriff
5. Alle Passwortabfragen entfernen
6. Netzwerk- und Freigabecenter → Passwortgeschützte Freigabe deaktivieren

Für Linux/Mac:
bash
# Samba installieren, falls nicht installiert
sudo apt install samba
sudo nano /etc/samba/smb.conf

# Am Ende hinzufügen:
[Musik]
path = /Pfad/zum/Ordner
browsable = yes
read only = yes
guest ok = yes
force user = nobody

# Samba neu starten
sudo systemctl restart smbd

2. VERBINDUNGSPROBLEME UND LÖSUNGEN:
Problem
Lösung
„Zugriff verweigert“
Passwortgeschützte Freigabe entfernen

„Netzwerkpfad nicht gefunden“
Firewall und IP-Adresse prüfen

„Mount-Fehler“
Gastoption anstelle von Benutzername/Passwort verwenden

Langsame Verbindung
Timeout in den Plugin-Einstellungen reduzieren

CiefpVibes v1.4 – Änderungsübersicht
Veröffentlichungsdatum: 13. Dezember 2025.
Wichtigste Verbesserungen:

Automatisches Update-System: Versionsprüfung über die version.txt-Datei auf GitHub hinzugefügt.

Das Plugin erkennt nun automatisch neue Versionen, zeigt den Status auf dem Bildschirm an (z. B. „Aktuell ✓“ oder „Update v1.5 verfügbar!“)
und bietet die Installation über eine MessageBox an. Das Sichern und Wiederherstellen von Konfigurationsdateien für sichere Updates ist ebenfalls enthalten.

Verbesserte Posterdarstellung: Deutlich verbesserte Erkennung von Songtiteln aus Dateinamen

(Seriennummern wie „01 -“, Jahreszahlen wie „(1993)“, Remix-Tags usw. werden ignoriert).

Verbesserte Suche in der iTunes-API mit Fallback auf den Interpreten, wenn keine Treffer pro Song gefunden werden. Der „Drosselungsmechanismus“ wurde korrigiert, um heruntergeladene Poster sofort anzuzeigen. Die Anzeigedauer des Standardposters wurde verkürzt.

Der Cache wurde präziser angepasst und das Flackern während der Wiedergabe beseitigt.

Weitere Verbesserungen und Korrekturen:

Verbesserte Handhabung von Online-TV-Playlists und lokalen MP3-Dateien.
Detailliertere Debug-Protokolle erleichtern die Fehlersuche. Die Zusammenarbeit mit Netzwerk-Mounts für die Verbindung mit einem Laptop wurde verbessert.

So aktualisieren Sie: Starten Sie das Plugin. Es prüft automatisch, ob eine neue Version auf GitHub verfügbar ist, und bietet die Installation an.
