CiefpVideoPlayer v1.5

- Πρόσθετο WebcamPlayer
Περιγραφή νέας λειτουργικότητας
Το WebcamPlayer είναι ένα νέο στοιχείο στο CiefpVideoPlayer v1.5 που επιτρέπει την προβολή και αναπαραγωγή ροών webcam από υπάρχοντα αρχεία userbouquet του Enigma2.

Τι νέο υπάρχει;
Αυτόματη αναγνώριση μπουκέτου κάμερας web - Το πρόσθετο ανιχνεύει αυτόματα όλα τα αρχεία userbouquet που περιέχουν κάμερες web
τα αναγνωρίζει από ονόματα αρχείων όπως:
- userbouquet.web_cam____prenj___.tv,
- userbouquet.ciefpsettings_iptv_webcam.tv
- ή οποιοδήποτε αρχείο που περιέχει τη λέξη "webcam" ή "prenj")

Υποστήριξη για πολλαπλές μορφές ροής - Λειτουργεί με:
#SERVICE 5002:... (exteplayer3)
#SERVICE 4097:... (τυπικό πρόγραμμα αναπαραγωγής Enigma2)
#SERVICE 1:... (κλασικές υπηρεσίες)

Δύο λειτουργίες αναπαραγωγής:
Μονή αναπαραγωγή - αναπαράγει μόνο μία κάμερα web
Αναπαραγωγή λίστας αναπαραγωγής - αναπαράγει όλες τις κάμερες web με τη σειρά (αυτόματη εναλλαγή)

Μίνι πρόγραμμα αναπαραγωγής με αυτόματη εναλλαγή - Όταν ξεκινά μια λίστα αναπαραγωγής, εμφανίζεται ένα μικρό διαφανές πρόγραμμα αναπαραγωγής στο επάνω μέρος της οθόνης που εμφανίζει:
Κάμερα web που αναπαράγεται αυτήν τη στιγμή
Επόμενη κάμερα web σε σειρά
Αντίστροφη μέτρηση για την επόμενη κάμερα
Αριθμός κάμερας (π.χ. "Κάμερα: 5 από 120")

Στοιχεία ελέγχου αναπαραγωγής:
Κουμπί OK - παύση της αυτόματης εναλλαγής
Κουμπί ▲/▼ - χειροκίνητη εναλλαγή στην προηγούμενη/επόμενη κάμερα
Κουμπί EXIT - έξοδος από τη λίστα αναπαραγωγής

Ρυθμιζόμενη διάρκεια
- Ο χρήστης μπορεί να ορίσει πόσα δευτερόλεπτα θα εμφανίζεται κάθε κάμερα web πριν από την αυτόματη εναλλαγή στην επόμενη (15, 20, 25, 30, 40 ή 60 δευτερόλεπτα)
- Ρυθμιζόμενη διαφάνεια μίνι εμφάνισης - Η διαφάνεια του μίνι προγράμματος αναπαραγωγής μπορεί να ρυθμιστεί (20%, 30%, 50%, 80% ή 100%)

Πώς να το ξεκινήσετε;
Υπάρχουν δύο τρόποι για να ξεκινήσετε το WebcamPlayer:
Χρησιμοποιώντας το ΠΡΑΣΙΝΟ κουμπί (Τοπικό) → επιλέξτε "Webcam Player" από το μενού
Χρησιμοποιώντας το ΚΙΤΡΙΝΟ κουμπί (Δίκτυο) → επιλέξτε "Webcam Player" από το μενού
Στη συνέχεια, εμφανίζεται μια λίστα με όλα τα μπουκέτα κάμερας web που βρέθηκαν, επιλέξτε την επιθυμητή και ανοίγει η κύρια οθόνη του WebcamPlayer.

Η αυτόματη εναλλαγή επιτρέπει την παρακολούθηση πολλαπλών καμερών χωρίς χειροκίνητη εναλλαγή.
Οι σύνδεσμοι YouTube αγνοούνται αυτόματα (δεν μπορούν να αναπαραχθούν μέσω του τυπικού προγράμματος αναπαραγωγής).
Υποστηρίζει τόσο παλιές όσο και νέες μορφές αρχείων userbouquet.

# CiefpVideoPlayer v1.3

**Το CiefpVideoPlayer** είναι ένα προηγμένο πρόγραμμα αναπαραγωγής βίντεο για συσκευές Enigma2 με πλήρη έλεγχο αναπαραγωγής.

## 🎬 Βασικά Χαρακτηριστικά

### 📺 Προηγμένο Πρόγραμμα Αναπαραγωγής Βίντεο
- **Πλήρης Έλεγχος Αναπαραγωγής** – Αναπαραγωγή, Παύση, Διακοπή, Πίσω, Εμπρός
- **Απομνημόνευση Θέσης** – συνέχιση της παρακολούθησης από το σημείο που την αφήσατε
- **Ροές HTTP** – παύση και συνέχιση διαδικτυακού περιεχομένου
- **Υπότιτλοι** – υποστήριξη για ενσωματωμένους και εξωτερικούς υπότιτλους

### 📁 Υποστηριζόμενες Πηγές
- **Τοπικά Αρχεία** – HDD, USB, Κάρτες CF
- **Κοινόχρηστα Δίκτυα** – SMB/CIFS, NFS
- **Διαδικτυακές Ροές** – Λίστες Αναπαραγωγής M3U και Enigma2 .tv
- **Ανοιχτός Κατάλογος** – περιήγηση και αναπαραγωγή ταινιών/σειρών από διακομιστές HTTP

### 🎭 Ενσωμάτωση TMDB
- **Ταινίες** – λεπτομερείς πληροφορίες, αξιολογήσεις, ηθοποιοί (κίτρινο κουμπί)
- **Σειρές** – λεπτομέρειες για σεζόν, επεισόδια, ηθοποιούς (μπλε κουμπί)
- **Αφίσες** – αυτόματη προσωρινή αποθήκευση για ταχύτερη προβολή
- **Αξιολογήσεις IMDb** – μέσω OMDb API (προαιρετικό)

### 💾 Αποθήκευση στην προσωρινή μνήμη
- Οι αφίσες και τα μεταδεδομένα αποθηκεύονται στην προσωρινή μνήμη για ταχύτερη φόρτωση
- Ρυθμιζόμενο μέγεθος προσωρινής μνήμης
- Επιλογή αυτόματης διαγραφής κατά την έξοδο

## 🎮 Στοιχεία ελέγχου MoviePlayer

| Κουμπί | Λειτουργία |
|------|------|
| **Αναπαραγωγή/Παύση** | Παύση και συνέχιση |
| **Διακοπή** | Διακοπή αναπαραγωγής |
| **◀ ▶** | Επαναφορά/Γρήγορη προώθηση |
| **◀◀ ▶▶** | Σάρωση (γρήγορη προώθηση) |
| **Πληροφορίες** | Εμφάνιση πληροφοριών βίντεο |
| **Ήχος** | Επιλογή κομματιού ήχου |
| **Υπότιτλοι** | Ενεργοποίηση/απενεργοποίηση υποτίτλων |
| **Έξοδος** | Έξοδος από το πρόγραμμα αναπαραγωγής (θυμάται τη θέση!) |

## ⏯️ Συνέχιση αναπαραγωγής

Το MoviePlayer θυμάται αυτόματα τη θέση από την οποία σταματήσατε. Την επόμενη φορά που θα αναπαράγετε το ίδιο βίντεο, το Enigma2 θα σας ρωτήσει αν θέλετε να συνεχίσετε από εκεί που σταματήσατε.

**Υποστηρίζεται για:**
- ✅ Τοπικά αρχεία (HDD, USB)
- ✅ Κοινόχρηστα στοιχεία δικτύου (SMB/NFS)
- ✅ Ροές HTTP (Ανοιχτός Κατάλογος)
- ✅ Λίστες αναπαραγωγής M3U και .tv

## 🚀 Πώς λειτουργεί

**Παλιός τρόπος (v1.2 και παλαιότερες):**

ref = eServiceReference(4097, 0, path)
session.nav.playService(ref) # Χωρίς έλεγχο, χωρίς συνέχιση

Νέος τρόπος (v1.3):

ref = eServiceReference(4097, 0, path)
ref.setName(name)
session.open(MoviePlayer, ref) # Πλήρης έλεγχος, υποστήριξη συνέχισης!
