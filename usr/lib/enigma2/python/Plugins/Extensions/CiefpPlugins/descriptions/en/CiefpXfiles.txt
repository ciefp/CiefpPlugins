

📺 CiefpXfiles - Xtream IPTV Plugin for Enigma2
CiefpXfiles is an advanced IPTV plugin for Enigma2 (Python 3) that allows you to watch Xtream Codes streams via a beautiful FHD interface,
featuring automatic retrieval of posters and descriptions from TMDB/OMDb, as well as translation of descriptions into Serbian using GROQ AI.

The plugin is the result of extensive work focused on optimization, stability, and—above all—the visual experience.
Emphasis has been placed on an FHD interface, high performance, and the automatic enrichment of content (posters, descriptions, ratings).
The plugin was created by merging several of my previous plugins into one:
- Integration with TMDB/OMDb (derived from the CiefpTMDBsearch plugin).
- Portal connectivity (derived from the CiefpE2Converter plugin).
- Translation of plot descriptions using the GROQ API key (derived from the CiefpEPGinfo plugin).
Much of the credit for bringing these ideas to life goes to the AI ​​"Deepseek,"
which assisted me in realizing my vision and specific requirements.

✨ Key Features
Support for Xtream Codes and M3U — Enter your playlist or Xtream credentials.
FHD Interface — A modern, 3-panel design (categories, information, poster).
TMDB and OMDb Integration — Automatically displays posters, descriptions, cast, directors, and IMDb ratings.
GROQ AI Translation — Automatically translates movie descriptions into Serbian (or another language).
Search — Quickly search for movies and series by title (using the INFO button).
Portal Status — Green/red indicators for online/offline servers. Automatic update — The plugin notifies you when a new version is available.
System folder — All data is stored in /etc/enigma2/CiefpXfiles/.

⚙️ Configuration
After installation, open the plugin from the menu. You will need to enter your API keys the first time you use it.
Press MENU (or SETTINGS at the bottom of the screen).

Enter the following keys:
TMDB API Key — Available for free at themoviedb.org. -- (tmdbapikey.txt)
OMDb API Key — Available for free at omdbapi.com. -- (omdbapikey.txt)
GROQ API Key — Available for free at console.groq.com. -- (groqapikey.txt)
SUBDL API Key — Optional, for subtitles. -- (subdlapikey.txt)
The SUBDL API key is not currently in use, but it is included in preparation for future versions.

Location for API keys: /etc/enigma2/CiefpXfiles/keys/
Configure the subtitle language, player type, and other options.
Click the Green button (Save). 📂 Location and files:
/etc/enigma2/CiefpXfiles/
playlist.txt
portals_cache.json
/etc/enigma2/CiefpXfiles/keys/
tmdbapikey.txt,omdbapikey.txt,groqapikey.txt,subdlapikey.txt
/etc/enigma2/CiefpXfiles/posters/
/etc/enigma2/CiefpXfiles/subtitles/
/etc/enigma2/CiefpXfiles/epg/

📂 New file structure (Security):
All your data (API keys, poster cache, playlists) are now stored in a secure location: /etc/enigma2/CiefpXfiles/.
This means that when you update or reinstall the plugin, your keys and lists remain saved.


📁 Playlist.txt
You can add to the playlist in two ways:

Format A (Structured)
text
Host:http://server:port
Username: xxxx
Password: xxxx
m3u:http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
EPG: http://server:port/xmltv.php?username=xxxx&password=xxxx

Format B (M3U links only)
text
http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
http://server:port/xmltv.php?username=xxxx&password=xxxx
The file playlist.txt is located in /etc/enigma2/CiefpXfiles/playlist.txt.
