📺 CiefpXfiles – Xtream IPTV-Plugin für Enigma2
CiefpXfiles ist ein fortschrittliches IPTV-Plugin für Enigma2 (Python 3), mit dem Sie Xtream-Codes-Streams über eine ansprechende FHD-Benutzeroberfläche ansehen können.
Es bietet den automatischen Abruf von Postern und Beschreibungen von TMDB/OMDb sowie die Übersetzung von Inhaltsbeschreibungen ins Serbische mithilfe von GROQ AI.

Das Plugin ist das Ergebnis umfangreicher Arbeit, bei der der Fokus auf Optimierung, Stabilität und – vor allem – auf einem ansprechenden visuellen Erlebnis lag.
Besonderer Wert wurde auf eine FHD-Benutzeroberfläche, hohe Performance und die automatische Anreicherung von Inhalten (Poster, Beschreibungen, Bewertungen) gelegt.
Das Plugin entstand durch die Zusammenführung mehrerer meiner früheren Plugins:
- Integration von TMDB/OMDb (basiert auf dem Plugin CiefpTMDBsearch).
- Portal-Anbindung (basiert auf dem Plugin CiefpE2Converter).
- Übersetzung von Handlungsbeschreibungen mittels GROQ-API-Schlüssel (basiert auf dem Plugin CiefpEPGinfo).
Ein großer Teil des Erfolgs bei der Umsetzung dieser Ideen gebührt der KI „Deepseek“,
die mich dabei unterstützte, meine Vision und spezifischen Anforderungen zu realisieren.

✨ Hauptfunktionen
Unterstützung für Xtream Codes und M3U – Geben Sie einfach Ihre Playlist oder Ihre Xtream-Zugangsdaten ein.
FHD-Benutzeroberfläche – Modernes 3-Bereiche-Design (Kategorien, Informationen, Poster).
TMDB- und OMDb-Integration – Automatische Anzeige von Postern, Beschreibungen, Besetzung, Regisseuren und IMDb-Bewertungen.
GROQ AI-Übersetzung – Automatische Übersetzung von Filmbeschreibungen ins Serbische (oder eine andere Sprache).
Suchfunktion – Schnelles Suchen nach Filmen und Serien anhand des Titels (über die INFO-Taste).
Portal-Status – Grün/Rot-Anzeigen für Online-/Offline-Server. Automatische Updates – Das Plugin benachrichtigt Sie, sobald eine neue Version verfügbar ist.
Systemordner – Alle Daten werden unter /etc/enigma2/CiefpXfiles/ gespeichert.

⚙️ Konfiguration
Öffnen Sie das Plugin nach der Installation über das Menü. Bei der ersten Verwendung müssen Sie Ihre API-Schlüssel eingeben.
Drücken Sie dazu die Taste MENU (oder wählen Sie SETTINGS am unteren Bildschirmrand). Geben Sie die folgenden Schlüssel ein:
TMDB-API-Schlüssel — Kostenlos erhältlich unter themoviedb.org. -- (tmdbapikey.txt)
OMDb-API-Schlüssel — Kostenlos erhältlich unter omdbapi.com. -- (omdbapikey.txt)
GROQ-API-Schlüssel — Kostenlos erhältlich unter console.groq.com. -- (groqapikey.txt)
SUBDL-API-Schlüssel — Optional, für Untertitel. -- (subdlapikey.txt)
Der SUBDL-API-Schlüssel wird derzeit noch nicht verwendet, ist aber bereits für zukünftige Versionen hinterlegt.

Speicherort für API-Schlüssel: /etc/enigma2/CiefpXfiles/keys/
Konfigurieren Sie die Untertitelsprache, den Playertyp sowie weitere Optionen.
Drücken Sie die grüne Taste (Speichern). 📂 Speicherort und Dateien:
/etc/enigma2/CiefpXfiles/
playlist.txt
portals_cache.json
/etc/enigma2/CiefpXfiles/keys/
tmdbapikey.txt, omdbapikey.txt, groqapikey.txt, subdlapikey.txt
/etc/enigma2/CiefpXfiles/posters/
/etc/enigma2/CiefpXfiles/subtitles/
/etc/enigma2/CiefpXfiles/epg/

📂 Neue Dateistruktur (Sicherheit):
Alle Ihre Daten (API-Schlüssel, Poster-Cache, Wiedergabelisten) werden nun an einem sicheren Ort gespeichert: /etc/enigma2/CiefpXfiles/.
Das bedeutet, dass Ihre Schlüssel und Listen auch bei einer Aktualisierung oder Neuinstallation des Plugins erhalten bleiben. 📁 Playlist.txt
Du kannst die Playlist auf zwei Arten erweitern:

Format A (Strukturiert)
text
Host:http://server:port
Username: xxxx
Password: xxxx
m3u:http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
EPG: http://server:port/xmltv.php?username=xxxx&password=xxxx

Format B (Nur M3U-Links)
text
http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
http://server:port/xmltv.php?username=xxxx&password=xxxx
Die Datei playlist.txt befindet sich unter /etc/enigma2/CiefpXfiles/playlist.txt.

🎮 Fernbedienungs-Kurzbefehle
Taste	Funktion
OK	Kategorie öffnen / Stream abspielen
EXIT	Plugin schließen
Grün	Live-TV
Gelb	Filme
Blau	TV-Serien
MENU	Einstellungen
INFO	Suche
