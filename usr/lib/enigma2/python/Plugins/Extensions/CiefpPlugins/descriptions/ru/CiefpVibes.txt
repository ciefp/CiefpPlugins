Примечания к выпуску CiefpVibes v2.2

Новый модуль: Загрузчик OpenDirectory
Добавлен совершенно новый модуль для загрузки музыки с серверов OpenDirectory!

Что такое OpenDirectory?

Общедоступные серверы для обмена музыкальными файлами (MP3, FLAC, M4A и т. д.)
Удобный просмотр и загрузка без сложных API

Особенности:
🌐 Просмотр серверов OpenDirectory — загрузка URL-адресов из файла opendir.txt
📁 Навигация по папкам — удобная навигация по каталогам
🎵 Выбор файлов — добавление отдельных песен или всей папки сразу
⬇️ Менеджер загрузок — загрузка файлов MP3, FLAC, M4A, AAC, WAV, OGG

📊 Индикатор выполнения — визуальное отображение хода загрузки
💾 Настраиваемый путь — выберите, куда будут сохраняться загруженные файлы

Как использовать:
Добавьте URL-адреса OpenDirectory в файл:
/usr/lib/enigma2/python/Plugins/Extensions/CiefpVibes/opendir.txt
Запустите CiefpVibes → Онлайн-файлы → Загрузчик OpenDirectory

Навигация:
OK - перейти в папку / добавить файл
Синяя кнопка - Выбрать все (добавляет все файлы из папки)
Желтая кнопка - Скачать (загружает выбранные файлы)
Зеленая кнопка - Настройки (задать путь)

Улучшения:
Автоматическая очистка имен файлов (удаляет подчеркивания, повторяющиеся расширения)
Умное именование (например, A-Ha_-_Take_On_Me.mp3 → A-Ha - Take On Me.mp3)

Ведение журнала всех загрузок
Быстрый выбор всех файлов из папки (без рекурсивного сканирования)

Требования:
Python 3
beautifulsoup4 (необязательно, для лучшего анализа)
Установка:
opkg install python3-beautifulsoup4

Вкратце:
теперь вы можете напрямую загружать музыку с общедоступных серверов OpenDirectory на ваше устройство Enigma2! 🎵

- Плагин музыкального проигрывателя для Enigma2

### Описание:
CiefpVibes — отличный плагин музыкального проигрывателя для устройств Enigma2.
Воспроизводит локальные или онлайн-плейлисты (.m3u/.tv) с повтором, перемешиванием,
настраиваемыми фонами и интеграцией с GitHub для получения новых песен.
Поддерживаются форматы mp3 и flac.
Идеально подходит для создания непрерывной атмосферы!

### Использование:
Начните из меню «Плагины».
Зеленый: Загрузить локальный файл.
Синий: Онлайн из GitHub.
Желтый: Настройки.
Красный: Выход.
Перейдите по плейлисту, нажмите «ОК» для воспроизведения.
Автоматически сохраняет последнюю сессию.

🔗 ИНСТРУКЦИЯ ПО УСТАНОВЛЕНИЮ СЕТЕВОГО СОЕДИНЕНИЯ
1. ЧТО НЕОБХОДИМО СДЕЛАТЬ НА НОУТБУКЕ/КОМПЬЮТЕРЕ:

Для Windows:
bash
1. Щелкните правой кнопкой мыши по папке → «Свойства»
2. Вкладка «Общий доступ» → «Расширенные настройки общего доступа»
3. ✅ Поделиться его папку
4. «Разрешения» → Добавить «Всем» → Полный доступ
5. Удалить все запросы пароля
6. Центр управления сетями и общим доступом → Отключить общий доступ, защищенный паролем

Для Linux/Mac:
bash
# Установите Samba, если она не установлена
sudo apt install samba
sudo nano /etc/samba/smb.conf

# Добавьте в конец:
[Музыка]
path = /path/to/folder
browseable = yes
read only = yes
guest ok = yes
force user = nobody

# Перезапустите Samba
sudo systemctl restart smbd

2. ПРОБЛЕМЫ С ПОДКЛЮЧЕНИЕМ И РЕШЕНИЯ:
Проблема Решение
"Доступ запрещен" Удалить общий доступ, защищенный паролем
"Сетевой путь не найден" Проверить брандмауэр и IP-адрес
"Ошибка монтирования" Использовать опцию guest вместо user/pass
Медленное соединение Уменьшить время ожидания в настройках плагина
