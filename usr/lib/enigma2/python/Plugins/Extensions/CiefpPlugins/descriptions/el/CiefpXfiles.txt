📺 CiefpXfiles - Πρόσθετο Xtream IPTV για Enigma2
Το CiefpXfiles είναι ένα προηγμένο πρόσθετο (plugin) IPTV για Enigma2 (Python 3), το οποίο σας επιτρέπει να παρακολουθείτε ροές (streams) από Xtream Codes μέσω ενός καλαίσθητου περιβάλλοντος εργασίας FHD.
Διαθέτει δυνατότητα αυτόματης ανάκτησης αφισών και περιγραφών από τα TMDB/OMDb, καθώς και μετάφραση των περιγραφών στα Σερβικά με τη χρήση του GROQ AI.

Το πρόσθετο αποτελεί καρπό εκτενούς εργασίας με εστίαση στη βελτιστοποίηση, τη σταθερότητα και —πάνω απ' όλα— την οπτική εμπειρία.
Δόθηκε ιδιαίτερη έμφαση σε ένα περιβάλλον εργασίας FHD, στην υψηλή απόδοση και στον αυτόματο εμπλουτισμό του περιεχομένου (αφίσες, περιγραφές, βαθμολογίες).
Το πρόσθετο δημιουργήθηκε μέσω της συγχώνευσης αρκετών προηγούμενων εργαλείων μου σε ένα ενιαίο σύνολο:
- Ενσωμάτωση με TMDB/OMDb (προέρχεται από το πρόσθετο CiefpTMDBsearch).
- Συνδεσιμότητα με πύλες (portals) (προέρχεται από το πρόσθετο CiefpE2Converter).
- Μετάφραση περιγραφών πλοκής μέσω του κλειδιού API του GROQ (προέρχεται από το πρόσθετο CiefpEPGinfo).
Μεγάλο μέρος της συμβολής στην υλοποίηση αυτών των ιδεών ανήκει στην τεχνητή νοημοσύνη "Deepseek",
η οποία με βοήθησε να πραγματοποιήσω το όραμά μου και να καλύψω συγκεκριμένες απαιτήσεις.

✨ Κύρια Χαρακτηριστικά
Υποστήριξη για Xtream Codes και M3U — Εισαγάγετε τη λίστα αναπαραγωγής (playlist) ή τα διαπιστευτήρια Xtream σας.
Περιβάλλον εργασίας FHD — Μοντέρνος σχεδιασμός 3 τμημάτων (κατηγορίες, πληροφορίες, αφίσα).
Ενσωμάτωση TMDB και OMDb — Αυτόματη εμφάνιση αφισών, περιγραφών, συντελεστών (ηθοποιοί, σκηνοθέτες) και βαθμολογιών IMDb.
Μετάφραση μέσω GROQ AI — Αυτόματη μετάφραση περιγραφών ταινιών στα Σερβικά (ή σε άλλη γλώσσα).
Αναζήτηση — Γρήγορη αναζήτηση ταινιών και σειρών βάσει τίτλου (με χρήση του πλήκτρου INFO).
Κατάσταση Πύλης (Portal Status) — Ενδείξεις πράσινου/κόκκινου χρώματος για διακομιστές που είναι online/offline. Αυτόματη ενημέρωση — Το πρόσθετο σας ειδοποιεί όταν είναι διαθέσιμη μια νέα έκδοση.
Φάκελος συστήματος — Όλα τα δεδομένα αποθηκεύονται στη διαδρομή /etc/enigma2/CiefpXfiles/.

⚙️ Ρυθμίσεις
Μετά την εγκατάσταση, ανοίξτε το πρόσθετο από το μενού. Την πρώτη φορά που θα το χρησιμοποιήσετε, θα χρειαστεί να εισαγάγετε τα κλειδιά API σας.
Πατήστε το πλήκτρο MENU (ή την επιλογή SETTINGS στο κάτω μέρος της οθόνης). Εισαγάγετε τα ακόλουθα κλειδιά:
Κλειδί API TMDB — Διαθέσιμο δωρεάν στο themoviedb.org. -- (tmdbapikey.txt)
Κλειδί API OMDb — Διαθέσιμο δωρεάν στο omdbapi.com. -- (omdbapikey.txt)
Κλειδί API GROQ — Διαθέσιμο δωρεάν στο console.groq.com. -- (groqapikey.txt)
Κλειδί API SUBDL — Προαιρετικό, για υπότιτλους. -- (subdlapikey.txt)
Το κλειδί API SUBDL δεν χρησιμοποιείται προς το παρόν, αλλά περιλαμβάνεται ενόψει μελλοντικών εκδόσεων.

Τοποθεσία για τα κλειδιά API: /etc/enigma2/CiefpXfiles/keys/
Ρυθμίστε τη γλώσσα των υποτίτλων, τον τύπο αναπαραγωγής (player) και άλλες επιλογές.
Πατήστε το πράσινο κουμπί (Αποθήκευση). 📂 Τοποθεσία και αρχεία:
/etc/enigma2/CiefpXfiles/
playlist.txt
portals_cache.json
/etc/enigma2/CiefpXfiles/keys/
tmdbapikey.txt,omdbapikey.txt,groqapikey.txt,subdlapikey.txt
/etc/enigma2/CiefpXfiles/posters/
/etc/enigma2/CiefpXfiles/subtitles/
/etc/enigma2/CiefpXfiles/epg/

📂 Νέα δομή αρχείων (Ασφάλεια):
Όλα τα δεδομένα σας (κλειδιά API, προσωρινή μνήμη αφισών, λίστες αναπαραγωγής) αποθηκεύονται πλέον σε μια ασφαλή τοποθεσία: /etc/enigma2/CiefpXfiles/.
Αυτό σημαίνει ότι, όταν ενημερώνετε ή επανεγκαθιστάτε το πρόσθετο (plugin), τα κλειδιά και οι λίστες σας παραμένουν αποθηκευμένα. 📁 Playlist.txt
Μπορείτε να προσθέσετε στοιχεία στη λίστα αναπαραγωγής (playlist) με δύο τρόπους:

Μορφή Α (Δομημένη)
text
Host:http://server:port
Username: xxxx
Password: xxxx
m3u:http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
EPG: http://server:port/xmltv.php?username=xxxx&password=xxxx

Μορφή Β (Μόνο σύνδεσμοι M3U)
text
http://server:port/get.php?username=xxxx&password=xxxx&type=m3u_plus&output=ts
http://server:port/xmltv.php?username=xxxx&password=xxxx
Το αρχείο playlist.txt βρίσκεται στη διαδρομή /etc/enigma2/CiefpXfiles/playlist.txt.

🎮 Συντομεύσεις Τηλεχειριστηρίου
Κουμπί	Λειτουργία
OK	Άνοιγμα κατηγορίας / Αναπαραγωγή ροής (stream)
EXIT	Κλείσιμο πρόσθετου (plugin)
Πράσινο	Ζωντανή τηλεόραση (Live TV)
Κίτρινο	Ταινίες
Μπλε	Τηλεοπτικές σειρές

INFO	Αναζήτηση
