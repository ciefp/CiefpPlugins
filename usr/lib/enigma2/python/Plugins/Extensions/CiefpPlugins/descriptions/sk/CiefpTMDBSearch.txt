Zatvorenie galérie:
Stlačením ČERVENÉHO tlačidla alebo OK/Ukončiť sa vrátite na hlavnú obrazovku pluginu.

..:: CiefpTMDBSearch v1.0 ::..

Vyhľadávajte filmy a seriály cez TMDB s plagátmi, popismi, hercami a hodnoteniami - v 14 jazykoch!

Vyžaduje sa iba bezplatný kľúč TMDB API (zadá sa raz pomocou žltého tlačidla).

# ZÁKLADNÉ FUNKCIE #
Vyhľadávanie filmov (ZELENÁ) a seriálov (ŽLTÁ)
Zobrazenie podrobností: názov, rok, trvanie, hodnotenie, žáner, režisér/tvorca, herci, popis
Stiahnutie plagátu (obalu) z TMDB
Podpora viacerých jazykov (popis, názvy)
Ukladanie plagátov do vyrovnávacej pamäte (rýchlejší prístup, menej internetovej prevádzky)
Manuálne nastavenie kľúča API TMDB

# INŠTALÁCIA A NASTAVENIE #
1. Kľúč API (POVINNÉ)
Zaregistrujte sa na themoviedb.org a získajte kľúč API
V plugine stlačte MODRÉ → Nastavenia → ŽLTÉ (Kľúč API)
Zadajte svoj kľúč API pomocou virtuálnej klávesnice

2. Kľúč API je uložený v súbore tmdbapikey.txt
Kľúč môžete zadať v textovom súbore tmdbapikey.txt
a preniesť ho do priečinka pluginu
pri spustení ho plugin načíta.

# POUŽITIE #
Hlavná ponuka:
ZELENÁ → Vyhľadávanie filmov
ŽLTÁ → Vyhľadávanie seriálov
MODRÁ → Nastavenia
RIADOK → Ukončiť

Príklad vyhľadávania:
Stlačte ZELENÉ tlačidlo pre filmy
Zadajte názov filmu (napr. "Inception")
Plugin zobrazí:
Názov, rok, trvanie
Hodnotenie (napr. 8,3/10 ★)
Žáner, režisér
Stručný popis deja
Hlavní herci
Plagát (ak je k dispozícii)

# NASTAVENIA (MODRÁ) #
Kľúč API (ŽLTÁ) - nastavte si kľúč
Jazyk (MODRÁ) - zmeňte jazyk
Stiahnuť plagáty - povoliť/zakázať sťahovanie plagátov
Vymazať vyrovnávaciu pamäť (MENU) - vymazať všetky uložené plagáty
Uložiť (ZELENÁ) - uložiť zmeny

# UKLADANIE DO VYRAMOVACIEJ PAMÄTE #
Plagáty sa automaticky ukladajú do /tmp/CiefpTMDBSearch/
Ukladá internetovú prevádzku počas opakovaného vyhľadávania
Ak chcete, môžete to vypnúť v nastaveniach

# PODPOROVANÉ JAZYKY #
Angličtina, srbčina, chorvátčina, bosniančina, slovenčina, nemčina, španielčina,
Francúzština, taliančina, ruština, portugalčina, poľština, turečtina, arabčina, čínština.

Testované a funguje perfektne na:
OpenATV · OpenBH · OpenPLI · Pure2 · Egami · OpenVision

Na navigáciu medzi obrázkami použite ŽLTÉ a MODRÉ tlačidlo (alebo šípky doľava/doprava).

ZELENÉ tlačidlo vás vráti na domovskú obrazovku alebo prepína medzi galériou pozadia a plagátov (ak je to možné).

Stavový riadok v hornej časti zobrazuje, z ktorého obrázka sa nachádzate a koľko z celkového počtu (napr. „6/185“).

Zatvorenie galérie:
Stlačením ČERVENÉHO tlačidla alebo OK/Ukončiť sa vrátite na hlavnú obrazovku pluginu.

💡 Tipy a poznámky
Ukladanie do vyrovnávacej pamäte: Obrázky sa automaticky sťahujú a ukladajú do vybraného priečinka vyrovnávacej pamäte (nastaveného v Nastaveniach). Toto zrýchli zobrazenie pri ďalšom otvorení.
Nastavenie jazyka: V Nastaveniach môžete zmeniť jazyk popisov. Toto ovplyvní aj jazyk údajov, ktoré prijímate z databázy TMDB.
Výkon: Ak plugin začne pracovať pomalšie kvôli plnej vyrovnávacej pamäti, môžete ju vymazať cez MENU > Ďalšie možnosti > 🗑️ Vymazať vyrovnávaciu pamäť.
Nová galéria je skvelým doplnkom, ktorý poskytuje používateľom plnohodnotný zážitok zo sledovania vizuálneho obsahu filmu alebo seriálu.
