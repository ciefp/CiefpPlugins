..:: CiefpEPGinfo v1.2 ::..
Информация о программе передач в формате FHD с использованием TMDB/OMDb/GROQ

📺 Новый плагин Enigma2 – отображает список программ передач и подробную информацию о фильмах/сериалах на одном экране!

✨ ОСОБЕННОСТИ:
• Список EPG – текущие + следующие 11 событий
• Интеграция с TMDB – постер, рейтинг, жанр, режиссер, сюжет
• Рейтинг IMDB через OMDb
• Перевод GROQ AI – более 20 языков
• Отображение Cast 2×5
• Браузер фильмографии – фильмография актеров
• Исследователь актеров – профиль актера на одном экране
• Трейлер YouTube (кнопка «Информация»)
• Интеллектуальные заполнители (спорт, новости, музыка, детские, документальные)
• Обнаружение не-TMDB (граница слов)
• Интеллектуальный поиск TMDB (по сходству названий)
• Автоматическая проверка обновлений
• Скин FHD (1920×1080)

🔑 НЕОБХОДИМЫЕ КЛЮЧИ API (бесплатные):
• TMDB: https://www.themoviedb.org/settings/api
• OMDb: https://www.omdbapi.com/apikey.aspx
• GROQ: https://console.groq.com/keys

Альтернативный вариант – файлы
Вы также можете создать файлы вручную в папке плагина:
- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/tmdbapikey.txt
- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/omdbapikey.txt
- /usr/lib/enigma2/python/Plugins/Extensions/CiefpEPGinfo/groqapikey.txt
Плагин автоматически загрузит их при запуске.

# ⚙️ Настройки
Описание параметров
- Ключ API TMDB Ключ TMDB
- Ключ API OMDb Ключ OMDb (рейтинги IMDb)
- Ключ API GROQ Ключ GROQ (перевод)
- Модель GROQ Модель перевода (GPT-OSS, Llama, Qwen, ...)
- Папка кэша Папка для хранения постеров
- Загрузка постеров ДА/НЕТ
- Отображение рейтинга IMDB ДА/НЕТ
- Язык описания Язык описания TMDB (en-US, sr-RS, ...)
- Перевод GROQ ДА/НЕТ – главный переключатель
- Перевод на язык перевода (sr, hr, en, ar, ...)
→ Описание EPG Перевод описания EPG
→ Сюжет TMDB Перевод описания TMDB
→ Биография Перевод биографии актера
→ Заголовки Перевод заголовков (медленнее)
Размер кэша Отображение размера кэша
ОЧИСТИТЬ КЭШ Удалить все постеры из кэша
Ручное обновление Проверить наличие новой версии вручную
