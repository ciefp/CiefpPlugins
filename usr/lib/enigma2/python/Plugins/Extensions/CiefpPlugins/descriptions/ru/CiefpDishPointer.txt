CiefpDishPointer v1.1
Плагин для Enigma2 (Python 2 и Python 3)

ОПИСАНИЕ:
Плагин, помогающий новичкам совместно использовать антенну — устанавливать нулевой
спутник для проверки правильности настройки антенны и настраивать
все необходимые углы для регулировки (азимут, угол места, наклон LNB).

По принципу работы сайта dishpointer.com, адаптирован для системы Enigma2.

Я не тестировал Python2

ОСНОВНЫЕ ФУНКЦИИ:

▶ Автоматическая геолокация
- Определение местоположения по IP-адресу (ip-api.com)
- Отображение: континент, территория, уклон, широта и долгота
- Возможность ручного изменения с помощью кнопки INFO

▶ Четыре режима подсказок
- Все спутники — показывает ближайший к вашему местоположению спутник
- Моторизованный — вычисляет истинный Юг/Север и склонение
- Многоканальный LNB — выбор нескольких спутников, плагин с нулевым бюджетом
- Одиночный — выбор одного спутника из списка

▶ Расчеты
- Истинный и магнитный азимут
- Угол возвышения
- Наклон LNB (влево/вправо)
- Склонение для моторизованной системы

▶ Одиночный спутник (зеленая кнопка)
- Список всех спутников из satellites.xml
- Выбор одного спутника стрелками
- Отображение вычисленных углов для выбранного спутника

▶ Многоканальный LNB (желтая кнопка)
- Список спутников с флажками
- Вы отмечаете несколько спутников, за которыми следите.
- Плагин бюджета — лучший нулевой спутник.
- Отображает список выбранных спутников и их среднее положение.

▶ Иллюстрации справки (plavo dugme)
- Иллюстрированное объяснение для:
• Высота (слишком мала/слишком велика)
• Азимут (ложная ось)
• Склонение (слишком велико/слишком мало)
• Наклон LNB
• Истинный Юг
• Настройка двигателя (4 праймера)

▶ Сигнал в реальном времени
- SNR с градиентной шкалой (красный → желтый → зеленый)
- AGC с градиентной шкалой
- Значение DB (например, 16.38)
- Отображение текущего канала, провайдера и спутника

▶ Двуязычная поддержка
- Английский (по умолчанию)
- Сербский
- Изменение языка через кнопку МЕНЮ → Настройки → Язык

КНОПКИ/КЛАВИШИ НА ЭКРАНЕ:

КРАСНАЯ (ВЫХОД) — закрывает Плагин
ЗЕЛЕНЫЙ (ОДИН СПУТНИК) — открывает выбор одного спутника
ЖЕЛТЫЙ (МНОГО LNB) — открывает настройку нескольких LNB
ПЛАВ (ИЗОБРАЖЕНИЯ СПРАВКИ) — открывает пояснительные изображения
МЕНЮ (ЯЗЫК) — открывает настройки (язык, местоположение, обновление)
ИНФО (МЕСТОПОЛОЖЕНИЕ) — открывает ручную смену местоположения
ЛЕВО/СПРАВА — изменяет тип системы (Все/Моторизованная/Много/Один)
ВЫХОД — закрывает плагин
