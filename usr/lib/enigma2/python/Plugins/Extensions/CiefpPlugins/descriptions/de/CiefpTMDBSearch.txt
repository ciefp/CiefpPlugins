Das Plugin verfügt jetzt auch über eine Galerie mit allen verfügbaren Postern und Hintergrundbildern.

Das Plugin bietet jetzt:

✅ Automatische EPG-Suche – automatische Erkennung des aktuellen Programms
✅ Erweiterte Suche – Filme, Serien, Schauspieler, Regisseure
✅ Beliebte/Trend-Listen – Was ist gerade angesagt?
✅ Besetzungsübersicht – Erkundung der Besetzung
✅ Staffeln und Episoden – detaillierte Übersicht von Serien und Episoden
✅ TMDB- und IMDB-Bewertungen – zusätzliche Informationen
✅ Hintergrundbildgalerie – Übersicht der Hintergrundbilder
✅ Postergalerie – Übersicht der Poster
✅ Einstellungen – API-Schlüssel, Sprache, Cache

🖼️ Kurzanleitung: So verwenden Sie die Poster- und Hintergrundbildansicht
Die neue Galerie ist einfach zu bedienen. Hier eine Kurzanleitung:

Zugriff auf die Galerie:
Nachdem die Film- oder Seriendaten geladen wurden, drücken Sie die MENU-Taste auf der Fernbedienung.

Wählen Sie im Menü die Option 🖼️ Hintergrundbildgalerie oder 🎬 Postergalerie.

Navigation durch die Galerie: Verwenden Sie die GELBEN und BLAUEN Schaltflächen (oder die Pfeiltasten links/rechts), um durch die Bilder zu blättern.

Die GRÜNE Schaltfläche führt Sie zurück zum Startbildschirm oder wechselt zwischen der Hintergrundbild- und der Postergalerie (sofern verfügbar). Die Statusleiste oben zeigt an, welches Bild Sie gerade geöffnet haben (z. B. „6/185“).

Galerie schließen: Drücken Sie die ROTE Schaltfläche oder OK/Beenden, um zum Hauptbildschirm des Plugins zurückzukehren.

💡 Tipps und Hinweise
Zwischenspeicherung: Bilder werden automatisch heruntergeladen und in Ihrem ausgewählten Cache-Ordner (in den Einstellungen festgelegt) gespeichert. Dies beschleunigt die Anzeige beim nächsten Öffnen.
Spracheinstellungen: In den Einstellungen können Sie die Sprache der Beschreibungen ändern. Dies wirkt sich auch auf die Sprache der Daten aus der TMDB-Datenbank aus.
Leistung: Falls das Plugin aufgrund eines vollen Caches langsam arbeitet, können Sie diesen über MENÜ > Weitere Optionen > 🗑️ Cache leeren leeren leeren.

Die neue Galerie ist eine großartige Ergänzung, die es Nutzern ermöglicht, die visuellen Inhalte eines Films oder einer Serie in vollen Zügen zu genießen.

..:: CiefpTMDBSearch v1.0 ::..

Suchen Sie Filme und Serien in der TMDB mit Postern, Beschreibungen, Schauspielern und Bewertungen 
– in 14 Sprachen! Sie benötigen lediglich einen kostenlosen TMDB-API-Schlüssel (einmalige Eingabe über den gelben Button).

# GRUNDFUNKTIONEN #
Filme (GRÜN) und Serien (GELB) suchen
Details anzeigen: Titel, Jahr, Dauer, Bewertung, Genre, Regisseur/Schöpfer, Schauspieler, Beschreibung
Poster (Cover) von TMDB herunterladen
Mehrsprachige Unterstützung (Beschreibung, Titel)
Poster-Caching (schnellerer Zugriff, weniger Datenverkehr)
TMDB-API-Schlüssel manuell festlegen

# INSTALLATION UND EINRICHTUNG #
1. API-Schlüssel (ERFORDERLICH)
Registrieren Sie sich auf themoviedb.org und erhalten Sie einen API-Schlüssel.
Im Plugin auf BLAU → Einstellungen → GELB (API-Schlüssel) klicken.
Geben Sie Ihren API-Schlüssel über die virtuelle Tastatur ein.
2. Der API-Schlüssel ist in der Datei tmdbapikey.txt gespeichert.
Sie können den Schlüssel in die Textdatei tmdbapikey.txt eingeben
und diese in den Plugin-Ordner verschieben.
Beim Start des Plugins wird er automatisch eingelesen.

# ANWENDUNG #
Hauptmenü:
GRÜN → Filme suchen
GELB → Seriensuche
BLAU → Einstellungen
ZEILE → Beenden

Suchbeispiel:
Drücken Sie GRÜN für Filme.
Geben Sie den Filmnamen ein (z. B. „Inception“).
Das Plugin zeigt Folgendes an:
Titel, Jahr, Dauer
Bewertung (z. B. 8,3/10 ★)
Genre, Regisseur
Kurzbeschreibung der Handlung
Hauptdarsteller
Poster (falls verfügbar)

# EINSTELLUNGEN (BLAU) #
API-Schlüssel (GELB) – Schlüssel festlegen
Sprache (BLAU) – Sprache ändern
Poster herunterladen – Poster-Download aktivieren/deaktivieren
Cache leeren (MENÜ) – Alle gespeicherten Poster löschen
Speichern (GRÜN) – Änderungen speichern

# CACHING #
Poster werden automatisch in /tmp/CiefpTMDBSearch/ gespeichert. Dies spart Datenvolumen bei wiederholten Suchen.
Sie können dies in den Einstellungen deaktivieren.

# Unterstützte Sprachen:
Englisch, Serbisch, Kroatisch, Bosnisch, Slowakisch, Deutsch, Spanisch, Französisch, Italienisch, Russisch, Portugiesisch, Polnisch, Türkisch, Arabisch, Chinesisch.

Getestet und funktioniert einwandfrei auf:
OpenATV · OpenBH · OpenPLI · Pure2 · Egami · OpenVision

Das beste TMDB-Info-Plugin für Enigma2
Jetzt mit automatischer EPG-Suche!
Erhalten Sie alle Informationen zu Filmen/Serien (Poster, Bewertung, Besetzung, Handlung usw.) direkt auf Ihrem Enigma2-Receiver – kein Smartphone oder Computer erforderlich!
Neu in Version 1.2:

Automatische EPG-Suche (BLAUE Taste) – Drücken Sie einfach die BLAUE Taste, während Sie einen beliebigen Kanal schauen.
Das Plugin lädt automatisch den aktuellen Programmtitel/das Jahr aus dem EPG herunter und durchsucht die TMDB! Intelligente Titelbereinigung (entfernt [HD], (2024), Film: usw.)
Es werden sowohl Film → Serie als auch Serie → Film durchsucht, bis das korrekte Ergebnis gefunden ist.
Deutlich verbesserte Erkennung des Erscheinungsjahres anhand der EPG-Beschreibung.
Schnelleres und zuverlässigeres Herunterladen und Zwischenspeichern von Postern.
15 Sprachen werden unterstützt (u. a. Serbisch, Kroatisch, Bosnisch, Englisch, Deutsch usw.).

Funktionen
Schönes, großes Poster (500×750) + alle Details auf einen Blick.
Vollständige Besetzungsliste mit Namen der Charaktere.
Regisseur/Produzenten, Genre, Laufzeit, Bewertung ★.
Poster-Zwischenspeicherung (/tmp oder HDD) – blitzschnell nach dem ersten Download.
Option zum Leeren des Caches + Cache-Informationen.
Funktioniert einwandfrei mit allen modernen Enigma2-Images (OpenATV, OpenBH, VTI, BlackHole, Egami usw.).

Anwendung
Plugin installieren.
Erster Start → MENU → Einstellungen → drücken. GELBER Button → Geben Sie Ihren kostenlosen TMDB-API-Schlüssel ein
(Hier in 10 Sekunden herunterladen: https://www.themoviedb.org/settings/api)
Add-on über das Menü starten

Buttons

GRÜN – Manuelle Filmsuche
GELB – Manuelle Seriensuche
BLAU – Automatische Suche nach aktuellem EPG-Ereignis ← NEU UND GENIAL!
MENÜ – Einstellungen (Sprache, Cache-Ordner, Poster löschen…)
