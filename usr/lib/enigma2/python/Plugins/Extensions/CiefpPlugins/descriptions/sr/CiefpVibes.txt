CiefpVibes v2.2 Release Notes

Novi modul: OpenDirectory Downloader
Dodan je potpuno novi modul za preuzimanje muzike sa OpenDirectory servera!

Šta je OpenDirectory?

Javni serveri koji dijele muzičke fajlove (MP3, FLAC, M4A, itd.)
Jednostavan pregled i preuzimanje bez komplikovanih API-ja

Funkcionalnosti:
🌐 Pregled OpenDirectory servera - učitajte URL adrese iz opendir.txt fajla
📁 Navigacija kroz foldere - krećite se kroz direktorijume jednostavno
🎵 Selektovanje fajlova - dodajte pojedinačne pjesme ili cijeli folder odjednom
⬇️ Download menadžer - preuzima MP3, FLAC, M4A, AAC, WAV, OGG fajlove

📊 Progress bar - vizuelni prikaz napretka preuzimanja
💾 Podesiva putanja - birate gdje će se snimati preuzeti fajlovi

Kako koristiti:
Dodajte OpenDirectory URL-ove u fajl:
/usr/lib/enigma2/python/Plugins/Extensions/CiefpVibes/opendir.txt
Pokrenite CiefpVibes → Online Files → OpenDirectory Downloader

Navigacija:
OK - ulaz u folder / dodavanje fajla
Plavo dugme - Select All (dodaje sve fajlove iz foldera)
Žuto dugme - Download (preuzima selektovane fajlove)
Zeleno dugme - Settings (podešavanje putanje)

Poboljšanja:
Automatsko čišćenje naziva fajlova (uklanja underscore, duple ekstenzije)
Pametno imenovanje (npr. A-Ha_-_Take_On_Me.mp3 → A-Ha - Take On Me.mp3)

Logiranje svih download aktivnosti
Brza selekcija svih fajlova iz foldera (bez rekurzivnog skeniranja)

Zahtjevi:
Python 3
beautifulsoup4 (opciono, za bolje parsiranje)
Instalacija:
opkg install python3-beautifulsoup4

Ukratko: 
sada možete direktno preuzimati muziku sa javnih OpenDirectory servera direktno na vaš Enigma2 uređaj! 🎵

CiefpVibes v2.2 Release Notes

New module: OpenDirectory Downloader
A brand new module for downloading music from OpenDirectory servers has been added!

What is OpenDirectory?

Public servers that share music files (MP3, FLAC, M4A, etc.)
Easy browsing and downloading without complicated APIs

Features:
🌐 OpenDirectory server browsing - load URLs from opendir.txt file
📁 Folder navigation - navigate through directories easily
🎵 File selection - add individual songs or an entire folder at once
⬇️ Download manager - downloads MP3, FLAC, M4A, AAC, WAV, OGG files

📊 Progress bar - visual display of download progress
💾 Customizable path - choose where downloaded files will be saved

How to use:
Add OpenDirectory URLs to the file:
/usr/lib/enigma2/python/Plugins/Extensions/CiefpVibes/opendir.txt
Run CiefpVibes → Online Files → OpenDirectory Downloader

Navigation:
OK - enter folder / add file
Blue button - Select All (adds all files from folder)
Yellow button - Download (downloads selected files)
Green button - Settings (set path)

Improvements:
Automatically clean up file names (removes underscores, duplicate extensions)
Smart naming (e.g. A-Ha_-_Take_On_Me.mp3 → A-Ha - Take On Me.mp3)

Logging all download activities
Quick selection of all files from a folder (without recursive scanning)

Requirements:
Python 3
beautifulsoup4 (optional, for better parsing)
Installation:
opkg install python3-beautifulsoup4

In short:
now you can directly download music from public OpenDirectory servers directly to your Enigma2 device! 🎵

### 🎯 Kako se koristi:
Osnovne funkcije:
🟢 ZELENO - Pregled datoteka (lokalno)
🔵 PLAVO - Online liste (M3U, TV, RADIO)
🟡 ŽUTO - Setinzi
🔴 CRVENO - Izađi iz aplikacije

### Nova opcija - RADIO
Pritisnite 🔵 PLAVO - Online liste 
Izaberi RADIO ,mogućnost izbora raznih plej listi

Dodat GITHUB_RADIO_URL i podrška za .radio fajlove (u parsiranju, file browser-u i GitHub preuzimanju).
Poboljšano parsiranje .tv/.radio fajlova: Proširena detekcija audio streamova
(indikatori poput .mp3, .flac, /stream, rtmp://), sa izuzecima za video formate (.ts, .mp4 itd.).
Bolje parsiranje metapodataka: parseArtistTitle() za razdvajanje "artist - title" formata, 
podrška za ICY metadata, automatsko ažuriranje nowplaying teksta i postera.

### Nova opcija - Čišćenje keša:
Pritisnite 🟡 ŽUTO (Postavke)
Izaberi "🧹 Očisti predmemoriju"
Potvrdi brisanje u dijalogu
Keš će biti obrisan (posteri + liste)

### Vizuelna i Playback Poboljšanja:
- Dodat dinamički poster prikaz (showPoster(), showDefaultPoster()) 
  sa automatskim preuzimanjem album covera sa iTunes API-ja (fetchAlbumCover()).
- Dva progress bara: "progress_real" (tačan progress) i "progress_vibe" (pulsirajući zeleni bar za "vibe" efekat).
- Offline detekcija: Label za "offline_status" (npr. "Stream Offline"), 
  timer za proveru streama (checkStreamStatus()), reset statusa pri puštanju.
- Više opcija za skin: Do 10 background-a, postera i infobara (u 1.0 samo do 5).
- Automatsko puštanje prve pesme u welcome playlisti.

### Ostale opcije u setinzima:
▶ Reprodukcija - Ponavljanje, slučajni redosljed
🌐 Mreža - Timeauti, učitavanje URL-a
🎨 Pozadina - 10 pozadina

### 💾 Šta se čuva:

🔗 UPUTSTVO ZA USPOSTAVLJANJE MREŽNE KONEKCIJE
1. ŠTA JE POTREBNO URADITI NA LAPTOPU/RAČUNARU:

Za Windows:
bash
1. Desni klik na folder → "Properties"
2. "Sharing" tab → "Advanced Sharing"
3. ✅ Share this folder
4. "Permissions" → Add "Everyone" → Full Control
5. Ukloni sve zahteve za lozinku
6. Network and Sharing Center → Turn off password protected sharing

Za Linux/Mac:
bash
# Instaliraj Samba ako nije instaliran
sudo apt install samba
sudo nano /etc/samba/smb.conf

# Dodaj na kraj:
[Music]
   path = /putanja/do/foldera
   browseable = yes
   read only = yes
   guest ok = yes
   force user = nobody

# Restartuj Samba
sudo systemctl restart smbd

2. PROBLEMI SA KONEKCIJOM I REŠENJA:
Problem	Rešenje
"Access denied"	Ukloni password zaštićeno deljenje
"Network path not found"	Proveri firewall i IP adresu
"Mount error"	Koristi opciju guest umesto user/pass
Sporo povezivanje	Smanji timeout u plugin settings

3. NAJČEŠĆE KORIŠĆENE PUTANJE:
bash
//192.168.1.100/Music        # Windows bez autentikacije
//192.168.1.100/             # Root share
//imelaptopa/Public          # Public folder

4. PLUGIN SETTINGS ZA MREŽU:
Menu dugme → Network Options
Auto-scan → automatski pronalazi uređaje
SMB Guest mode → koristi guest bez lozinke
