CiefpVideoPlayer v1.5

- Плагин WebcamPlayer
Описание новой функциональности
WebcamPlayer — это новый компонент в CiefpVideoPlayer v1.5, который позволяет просматривать
и воспроизводить потоки с веб-камеры из существующих файлов пользовательских каталогов Enigma2.

Что нового?

Автоматическое распознавание букетов веб-камер — плагин автоматически обнаруживает все файлы userbouquet, содержащие веб-камеры,
распознает их по именам файлов, таким как:
- userbouquet.web_cam____prenj___.tv,
- userbouquet.ciefpsettings_iptv_webcam.tv
- или любому файлу, содержащему слово "webcam" или "prenj")

Поддержка нескольких форматов потоков — работает с:
#SERVICE 5002:... (exteplayer3)
#SERVICE 4097:... (стандартный плеер Enigma2)
#SERVICE 1:... (классические сервисы)

Два режима воспроизведения:
Воспроизведение одной веб-камеры — воспроизводит только одну веб-камеру
Воспроизведение по плейлисту — воспроизводит все веб-камеры по порядку (автоматическое переключение)

Мини-плеер с автоматическим переключением — при запуске плейлиста в верхней части экрана появляется небольшой прозрачный плеер, отображающий:
Текущая воспроизводимая веб-камера
Следующая веб-камера в Последовательность
Обратный отсчет до следующей камеры
Номер камеры (например, «Камера: 5 из 120»)

Управление воспроизведением:
Кнопка OK — приостанавливает автоматическое переключение
Кнопки ▲/▼ — ручное переключение на предыдущую/следующую камеру
Кнопка EXIT — выход из плейлиста

Регулируемая продолжительность
— Пользователь может установить, сколько секунд будет отображаться каждая веб-камера перед автоматическим переключением на следующую (15, 20, 25, 30, 40 или 60 секунд)
— Регулируемая прозрачность мини-плеера — Прозрачность мини-плеера можно установить (20%, 30%, 50%, 80% или 100%)

Как запустить?

Запустить WebcamPlayer можно двумя способами:
Используя ЗЕЛЕНУЮ кнопку (Локальный) → выберите «Webcam Player» в меню.
Используя ЖЕЛТУЮ кнопку (Сеть) → выберите «Webcam Player» в меню.
Затем отобразится список всех найденных пакетов веб-камер, выберите нужный, и откроется главный экран WebcamPlayer.

Автоматическое переключение позволяет отслеживать несколько камер без ручного переключения.
Ссылки на YouTube автоматически игнорируются (не воспроизводятся через стандартный плеер).
Поддерживаются как старые, так и новые форматы файлов пользовательских пакетов.

# CiefpVideoPlayer v1.3

**CiefpVideoPlayer** — это продвинутый видеоплеер для устройств Enigma2 с полным контролем воспроизведения.

## 🎬 Основные функции

### 📺 Расширенный видеоплеер
- **Полное управление воспроизведением** – Воспроизведение, Пауза, Стоп, Перемотка назад, Перемотка вперед
- **Запоминание позиции** – продолжение просмотра с того места, где вы остановились
- **HTTP-потоки** – пауза и возобновление просмотра онлайн-контента
- **Субтитры** – поддержка встроенных и внешних субтитров

### 📁 Поддерживаемые источники
- **Локальные файлы** – HDD, USB, CF-карты
- **Сетевые ресурсы** – SMB/CIFS, NFS
- **Онлайн-потоки** – плейлисты M3U и Enigma2 .tv
- **Открытый каталог** – просмотр и воспроизведение фильмов/сериалов с HTTP-серверов

### 🎭 Интеграция с TMDB
- **Фильмы** – подробная информация, рейтинги, актеры (желтая кнопка)
- **Сериалы** – информация о сезонах, Эпизоды, актеры (синяя кнопка)
- **Постеры** – автоматическое кэширование для более быстрого просмотра
- **Рейтинги IMDb** – через API OMDb (опционально)

### 💾 Кэширование
- Постеры и метаданные кэшируются для более быстрой загрузки
- Регулируемый размер кэша
- Опция автоматической очистки при выходе

## 🎮 Элементы управления MoviePlayer

| Кнопка | Функция |

|------|------|

| **Воспроизведение/Пауза** | Пауза и возобновление |

| **Стоп** | Остановить воспроизведение |

| **◀ ▶** | Перемотка назад/вперед |

| **◀◀ ▶▶** | Сканирование (перемотка вперед) |

| **Информация** | Показать информацию о видео |

| **Аудио** | Выбрать звуковую дорожку |

| **Субтитры** | Включить/выключить субтитры |

**Выход** | Выйти из плеера (запоминает позицию!) |

## ⏯️ Возобновить воспроизведение

MoviePlayer автоматически запоминает позицию, на которой вы остановились. При следующем воспроизведении того же видео Enigma2 спросит вас, хотите ли вы продолжить с того места, где остановились.


**Поддерживается для:**
- ✅ Локальных файлов (HDD, USB)
- ✅ Сетевых ресурсов (SMB/NFS)
- ✅ HTTP-потоков (Open Directory)
- ✅ Плейлистов M3U и .tv

## 🚀 Как это работает

**Старый способ (версия 1.2 и ранее):**

ref = eServiceReference(4097, 0, path)
session.nav.playService(ref) # Нет управления, нет возобновления воспроизведения

Новый способ (версия 1.3):

ref = eServiceReference(4097, 0, path)
ref.setName(name)
session.open(MoviePlayer, ref) # Полный контроль, поддержка возобновления воспроизведения!
